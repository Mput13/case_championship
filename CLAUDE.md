# Контекст проекта для Claude Code

Это рабочая папка команды на кейс-чемпионате МАИ «Связанность территорий» (https://mai-way.ru). Команда решает **кейс Red Wings «Новый хаб или прямые рейсы?»**.

1. **`docs/00_index_and_ideas.md` — главный файл**: карта всех документов, решения команды, реестр всех идей и гипотез, ключевые цифры, **ТЗ на расчёт** (структура кода, входные таблицы, параметры, что считать, листы Excel), чек-лист сдачи, открытые вопросы.

4. Флот, дальность, время, число самолётов — `docs/17`; светофор дальности — `tools/dist.py`.

## Решения команды (соблюдать во всех материалах)
- Флот — по официальному сайту: 28 ВС (20 SSJ100, 3 Ту-214, 2 Ту-204, 3 B777). Сообщения СМИ о простое B777 не упоминать.
- Гендиректор — Роман Чуев с 30.10.2026 (в справке организаторов устаревшее «Ивлиев»).
- B777 — честно указывать, что они старые и требуют больше ремонта и запчастей. Они остаются в **базовой линии** (текущие чартеры, входят в 2,7 млн пасс. 2025) и не перераспределяются; сеть гипотез (хаб/прямые) строится на SJ-100 + SSJ/Ту-214. Отдельно — «опция роста»: сезонные дальние рейсы B777 из хаба, которые кормят SJ-100 (не в основном расчёте). Риск B777 — в осторожном сценарии базовой линии.
- Запасной план: при задержке SJ-100 сеть держится на SSJ и Ту-214.
- Сценарии строим только вокруг «Ковра» и открытия закрытых аэропортов. Отмену санкций, возвращение Airbus/Boeing, новые самолёты и смену «дружественных» направлений НЕ рассматриваем. Своих прогнозов по СВО не делаем — только нейтральный обзор со ссылками.
- Дальность: каждый маршрут проходит «светофор» из docs/17 (SSJ/SJ-100 🟢 ≤ 2 300 км по прямой, Ту-204 ≤ 2 900, Ту-214 ≤ 3 350; юг — с коэффициентом 1,20). Жёлтые маршруты в основную сеть не включаем. SJ-100 до сертификации считаем как SSJ-95B.
- Пассажиров считаем в двух мерах: сегменты (как в статистике) и поездки «откуда — куда» (гипотеза Н1, docs/19).

## Правила для кода и расчётов
- Каждая цифра во входных данных — с колонкой `source` (ссылка или «допущение: …» / «синтетика: метод …»).
- Все допущения — в одном месте (лист/файл `assumptions`), базовый и осторожный сценарии переключаются параметром.
- Расчёт должен повторяться одной командой; в README описать, как запустить.
- Git: **pull не делать**; коммитить и пушить только по просьбе пользователя.
