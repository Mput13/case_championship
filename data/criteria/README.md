# Папка подключаемых критериев

Чтобы добавить критерий лонглиста, положите сюда CSV-файл и запустите обновление:

```
py -3.13 src/update.py --force
```

Критерий сам появится в расчёте баллов, на пульте весов, в посадочном талоне и, если нужно, на табло. Код править не нужно.

## Как устроен файл

Имя файла — ключ критерия латиницей, например `tourism.csv`. Одна строка на город.

| Колонка | Обязательно | Что писать |
|---|---|---|
| `iata` | да | код аэропорта города: KUF, UFA, OMS… |
| `value` | да | число; пусто, если данных нет (город получит нейтральную оценку и пометку «нет данных») |
| `source` | желательно | ссылка или «допущение: …» — откуда цифра |
| `text` | нет | как показать значение, если число нужно пояснить («скрыто Росавиацией») |
| `label` | нет | полное название критерия (берётся из первой строки) |
| `short` | нет | короткое название для столбца табло |
| `direction` | нет | `+` — больше лучше, `-` — меньше лучше (по умолчанию `+`) |
| `weight` | нет | вес по умолчанию; 0 — критерий виден, но в балл пока не входит |
| `fmt` | нет | как показывать число: `mln` (миллионы), `days`, `km`, `int`, `pct`, `yesno`, `num` |
| `board` | нет | `1` — показать столбцом на табло, `0` — только в талоне |
| `why` | нет | одна фраза: зачем этот критерий |

Пример: `pax_2019.csv` (его делает `src/fetch_favt_airports.py` из открытых данных Росавиации).
