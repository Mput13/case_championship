# ЗАДАЧА (пока не исследовано): наземное обслуживание, стоянки, ТО в хабе и на базах

Статус: **записано 08.11.2026, поиск ещё не делали**. Ниже — что нужно выяснить и какие данные искать. Источники во второй колонке — предположения о том, где искать, а не проверенные факты.

## Зачем это кейсу
- Хаб и прямые рейсы стоят по-разному не только из-за самолётов, но и из-за земли: стоянки, ТО, обслуживание, сборы, персонал.
- Без этого «Скрытые расходы прямых рейсов» (тезис 11 в docs/08) и стоимость хаба (docs/02) остаются словами без цифр.
- Это нужно для плана времени в docs/17 (время оборота, окна ТО, ночные стоянки).

## Что получить на выходе
1. Таблица по каждому аэропорту из топ-3 лонглиста + текущие базы: стоянки, ТО, топливо, сборы, транзитная зона, часы работы.
2. Оценка «стоимость земли» на один рейс и на один ночующий самолёт: хаб против рейсов из существующих баз.
3. Время оборота и окна ТО для docs/17 (вместо рабочих допущений).
4. Новый критерий для лонглиста: «готовность аэропорта к базированию».
