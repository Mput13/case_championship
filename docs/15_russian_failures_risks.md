## Что из этого следует для кейса — «не делать / где не делать / риски»
1. **Не строить хаб/базу на флоте без гарантий обслуживания** (Омск 2022, Уральские A320neo). B777 — в расчёт сети не включаем (возраст, дорогое обслуживание). Для SJ-100 — риск задержек поставок и «раскатки» → дорожная карта с запасным вариантом на SSJ/Ту-214. Для SSJ — дефицит запчастей SaM146, исправность парка ~77%, прогноз о выводе старых бортов к 2028 (подробно — docs/17).
1а. **Не ставить маршрут «на грани дальности»**: каждый маршрут — через светофор дальности из docs/17.
2. **Не опирать маршрут на субсидию** (Dexter 2017, сокращение 2023, задержка 2024, Breeze EAS): в осторожном сценарии маршрут должен выживать без субсидии.
3. **Не летать короткие пары с хорошим поездом/дорогой** (Dexter, ПФО).
4. **Где не делать хаб**: в аэропортах зоны закрытий и «Ковра» (Ростов 2022, юг 2026); в аэропорту без транзитной зоны (Омск до 2028); во вторичном аэропорту с плохим доступом и спорным статусом (уроки Жуковского).
5. **Топливный и долговой шок** (КрасЭйр 2008: топливо >50% расходов; ЮТэйр 2014; топливный кризис 2026) → стресс-сценарий по цене топлива.
6. **Регулятор и безопасность**: маленький флот + новый тип самолёта = высокий риск проверок (Ижавиа, Red Wings 2012).
7. **Не выходить из регионального соглашения в одностороннем порядке** — заложить в соглашение условия выхода и гарантии.
8. **Возможность**: уход слабых перевозчиков освобождает маршруты (Ижавиа → Екатеринбург — Ижевск у Red Wings; Омск 2022 → другие подхватили).
