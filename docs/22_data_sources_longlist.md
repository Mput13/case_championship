# 22. Откуда берём данные для лонглиста

Срез 09.11.2026. Для каждого критерия указано, где лежат данные, как их достаём и что уже сделано.

## Как это делают другие и почему у нас иначе

Авиакомпании и консультанты выбирают хаб по платным базам: расписания OAG и Cirium, продажи билетов MIDT (Sabre, Amadeus). У нас их нет. Росавиация раньше публиковала пассажиропоток по каждому аэропорту, но её открытые данные заканчиваются 2020 годом ([набор statperevaeroportpas](https://favt.gov.ru/opendata/7714549744-statperevaeroportpas/), последнее обновление 01.02.2021). Поэтому российские аналитики сейчас собирают картину из трёх частей: отчёты самих аэропортов, расписания и канал Росавиации об ограничениях. Так же делаем и мы.

Платный сервис [Aviastats](https://aviastats.ru/) от Aviasales даёт данные компаниям по запросу. Часть его данных (прямые рейсы на июнь–декабрь 2026 года) уже есть в открытом наборе «Если быть точным», и мы берём их оттуда.

| Население на 01.01.2024 (свежее переписи) | [Росстат, бюллетень по муниципальным образованиям](https://rosstat.gov.ru/compendium/document/13282) | Скачать вручную в браузере файл `BUL_MO_2024.xlsx` и положить в `data/raw/`. Скриптом сайт не отдаёт, он закрыт от программ | Нужен человек |

Засчитываются только типовые посты об аэропорте («ограничения на приём и выпуск», «по согласованию», сводные «не принимают и не отправляют») | Посчитано, 7 711 постов с 06.11.2024. Сверка за H1 2026: Казань 51 (Meduza 51), Калининград 1 (1), Владивосток, Иркутск, Хабаровск 0 (0), Сочи 61 (70). Для Казани за H1 2025 у нас 26 дней, у Meduza 32. Наш счёт — нижняя граница |

| Где уже есть прямые рейсы | «Если быть точным», фактические маршруты июнь–декабрь 2026 (Aviastats) и субсидии Росавиации | Скрипт: число направлений из города | Посчитано |
| Индекс неудобства поезда | «Если быть точным», время поездом (данные СберИндекса) | Скрипт: сколько людей в зоне SSJ, куда сейчас нет ни прямого рейса, ни поезда быстрее 12 часов (`gap_pop`) | Посчитано |
| Длина полосы | OurAirports runways.csv | Скрипт | Посчитано |
| Удалённость от Москвы и Екатеринбурга | OurAirports | Скрипт | Посчитано |

| Туризм | Росстат, «Регионы России», размещённые в гостиницах по регионам | Вручную из PDF (сайт Росстата закрыт от скриптов) | Не начато |

## Что нужно от людей

1. Ключ API Яндекс Расписаний: нужен для доли базового перевозчика и позже для частот на маршрутах.
2. Файл Росстата `BUL_MO_2024.xlsx`: открыть [страницу](https://rosstat.gov.ru/compendium/document/13282) в браузере, скачать, положить в `data/raw/`. Если браузер ругается на сертификат, на сайте Госуслуг есть инструкция по установке сертификата Минцифры; ставить его или нет, решаешь ты.

## Как повторить

```
py -3.13 src/fetch_static.py      # справочники OurAirports и «Точно»
py -3.13 src/fetch_kover.py --since 2024-11-01   # канал Росавиации, ~25 мин
py -3.13 src/kover_days.py        # дни «Ковра» по аэропортам
py -3.13 src/longlist_data.py     # расчётные критерии
```
