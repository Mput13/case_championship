# 22. Откуда берём данные для лонглиста

Срез 09.11.2026. Для каждого критерия указано, где лежат данные, как их достаём и что уже сделано.

## Как это делают другие и почему у нас иначе

Авиакомпании и консультанты выбирают хаб по платным базам: расписания OAG и Cirium, продажи билетов MIDT (Sabre, Amadeus). У нас их нет. Росавиация раньше публиковала пассажиропоток по каждому аэропорту, но её открытые данные заканчиваются 2020 годом ([набор statperevaeroportpas](https://favt.gov.ru/opendata/7714549744-statperevaeroportpas/), последнее обновление 01.02.2021). Поэтому российские аналитики сейчас собирают картину из трёх частей: отчёты самих аэропортов, расписания и канал Росавиации об ограничениях. Так же делаем и мы.

Платный сервис [Aviastats](https://aviastats.ru/) от Aviasales даёт данные компаниям по запросу. Часть его данных (прямые рейсы на июнь–декабрь 2026 года) уже есть в открытом наборе «Если быть точным», и мы берём их оттуда.

Что ещё изменилось:
- **Чужой хаб:** заполнен по шкале доказательности (`data/assumptions/evidence_ladder.csv`). 1 — первичный источник (Красноярск, Иркутск, Владивосток, Казань, Тюмень, Минводы, Сочи), 0,75 — Википедия называет хаб конкурента (Челябинск, Хабаровск), 0,25 — в карточке аэропорта хаб конкурента не указан (11 городов). Долю перевозчиков по расписанию без ключа Яндекс Расписаний не посчитать.
- **Ростех:** найдены ОДК-Кузнецов (Самара), НАЗ «Сокол» ОАК (Нижний Новгород), ОМО им. Баранова ОДК (Омск). У остальных городов предприятий ОДК/ОАК в 75 км не нашли; это слабое свидетельство, отмечено в источнике. Неизвестное значение теперь середина шкалы (раньше 0).
- **Диапазон из-за пропусков:** для каждого города считаем нижний и верхний балл (неизвестное худшее или лучшее) и лучшее и худшее возможное место. На панели это колонки «Место при пропусках» и «Вес на пропусках».
- **Наборы весов** (с 10.11.2026): основной набор коллег с суммой 100 и ещё пять для сравнения (`data/assumptions/weight_profiles.csv`); решения и итог — [docs/25](25_step1_open_questions.md).
- **До Москвы** теперь считаем до ближайшего из трёх аэропортов, раньше было только до Шереметьево.

Итог с фильтром 500 км: Омск, Оренбург, Самара. Омск первый во всех пяти сценариях весов, при пропусках его место 1–2. Без фильтра: Пермь, Уфа, Челябинск.

Не удалось заполнить: зона трансфера (13 городов) и круглосуточный режим (16 городов). Аэропорты публично об этом не пишут, нужно спросить их или посмотреть сборник аэронавигационной информации (AIP).

## Что нужно от людей

1. Ключ API Яндекс Расписаний: нужен для доли базового перевозчика и позже для частот на маршрутах.
