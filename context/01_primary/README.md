# Первичные материалы и каталог организаторов

Публичные требования: [чемпионат](https://mai-way.ru/) и [Red Wings](https://mai-way.ru/tasks/red-wings/). Их страницы прочитаны в Chrome; полный DOM хранится локально, не в Git.

В корне исходной рабочей папки уже находились PDF `5 кейс.pdf`, слайд Red Wings, презентация кейсов, шаблон паспорта DOCX и `case_championship_transcript.md`. Файлы не изменялись. Извлечённые тексты — в локальной папке `extracted/`, размеры и SHA-256 — в `local_manifest.json`. Наличие материалов с совпадающими названиями в Telegram подтверждено, побайтовое сравнение с повторной загрузкой вложений не выполнялось.

PDF и страница кейса — первичные источники **требований**, но статистическая справка внутри них составлена из других публикаций. Её нельзя считать независимым подтверждением отраслевых чисел. Расшифровка не сверена с аудио/видео и используется только как вспомогательный материал.

[Каталог данных организаторов](https://docs.google.com/spreadsheets/d/1lWth7AgxGWDGiAHEXNgSjNQTaCmZDxHrBlmADg6GWLQ/edit) прочитан и экспортирован через Chrome 7 ноября. В нём 38 строк, первоначально предназначенных для треков МАИ А1–А3. В [organizer_catalog.csv](organizer_catalog.csv) сохранены названия, ссылки и назначение. `CATALOG_ENTRY_ONLY` означает, что строка присутствует в каталоге, но соответствующий набор этой операцией не проверен. Экспорт CSV сам по себе потерял гиперссылки: ссылки восстановлены из ячеек XLSX, все 38 сопоставлены строкам.

Не все строки пригодны для Red Wings: морские порты и автомобильный рынок — вспомогательный контекст других кейсов. Население, авиационная инфраструктура и сравнение видов транспорта могут быть непосредственно полезны. Для доступных образцов и дальнейшей проверки см. [датасеты](../05_datasets/).

Полные исходники, экспорт XLSX с внутренними метаданными, расшифровка и DOM оставлены локально. Публичный пакет содержит указатели и подготовленные заметки.
