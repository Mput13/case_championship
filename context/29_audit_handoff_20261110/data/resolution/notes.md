# Адресное разрешение data operations

Pin `14354571b90545cd0618548481a857bf6b388d4a`, ветка `audit/end-to-end-20261110`. Изменения только в `data/resolution/`. Все 389 owner-хэшей до и после исполнения совпали. Inventory, город, стратегия, исходные веса и опубликованные результаты не изменены. Full pipeline, network replay, greedy selection и fitting сети/OD не выполнялись; чужие незавершённые outputs не использовались. Внешние документы не исследовались.

`site_resolution.csv` содержит ровно 307 уникальных исходных site IDs. 38 прежних finished checks перенесены ссылкой на `data/content/join_results.csv`, включая прежние ограничения raw projection. Из 269 дополнительных site IDs: **161** имеет finished exact population, **29** — complete domain envelope, **2** — conditional not reached, **77** — not executed с конкретной функцией/выражением и причиной. **190 дополнительных site IDs имеют фактическое исполнение**, но envelope не означает проверку реально выбранных оптимизатором маршрутов. Снижение числа unresolved за счёт классификации не использовано как доказательство истинности.

Классификация всех 307: 95 multi-input join/map; 116 unary group/filter/index; 32 key construction; 53 formatting/metadata; 9 control/plumbing; 2 conditional/nonconsumed. Это виды операций, не заключения о качестве первичных данных. `status=подтверждено` означает только перечисленную локальную проверку; факт, модель и непроверенные upstream зависимости этим не подтверждаются.

Исполнение: исходные AST expressions инструментируются в памяти; owner writes удалены, news writer направлен в StringIO, HTTP запрещён. Выполнены потребители сохранённых layers, точные преобразования schedule/seasonality/comparison, построение demand summary, criteria/dropins, локальные Kover predicates, три неизменённых ranking domains, parser/cache projections. Каждая CSV записана DictWriter; JSONL содержит actual receiver/output/null/duplicate/drop/missing-key observations. Ссылки `file:line` в overlay ведут к исходнику и JSONL. `attempts.json` сохраняет также неудачные попытки fixture evaluation: их ошибки не объявлены ошибками owner. `key_population_results.csv` — только новые реально исполненные sites; отдельные полные constructor/IATA/directed-undirected diagnostics — в `additional_key_diagnostics.csv`.

`binding_evidence` — лексическая цепочка определений из исходника. `inputpaths_and_requiredness` консервативно перечисляет path literals source reader; это не доказательство безусловного потребления каждого файла каждым site. Реальные read paths есть в evidence; точный receiver наблюдается только у исполненных операций. Ключ, тип и default/predicate сохранены исходным выражением и runtime receiver. Sparse NAME lookup использует `airport_names.csv` (airports_meta.py:14) с fallback на main_city: отсутствие override не объявлено потерей business join. Domain envelopes NAME/GROUP и persisted Demand.tab проверены отдельно; формульный fallback Demand требует отсутствующего intercity/rail и не принят.

`dependency_bindings.csv` содержит строку для каждого site, существующие field IDs лишь при доказанной лексической связи поля и writer в том же source. Precision явно ограничена; неизвестная transitive numeric lineage остаётся UNKNOWN. Эти связи не являются доказательством происхождения каждой опубликованной цифры.

CP1251: **15 исходных позиций схлопнулись в 8 legacy field IDs**. `encoding_field_aliases.csv` сохраняет все 8 IDs, массивы исходных индексов (0-based), все правильные названия и SHA256. Списки необходимы: одинаковый replacement header объединял разные месяцы. `patches/inventory_encoding.patch` предлагает строгий CP1251 decode и предупреждает о необходимой миграции; live inventory не перегенерирован. Применять patch без alias migration нельзя: новые семантические поля потребуют отдельных IDs, старые overlays должны сохранить историческую адресацию.

Residual: отсутствуют исходные OurAirports airports/runways, intercity, settlements, Rosstat workbook, wages, NOAA history/archives и Natural Earth/raw HTML для отдельных преобразований. Промежуточные processed tables не подставлялись вместо этих raw populations. Локальные карты S/legs/f/load/want/loc/sc внутри network selection не восстанавливались из готовых routes; они относятся к исключённому greedy computation. Transfer eligibility требует missing Demand direct/rail. Две news formatting branches не достигнуты на полном локальном scan с текущими guards. Точные строки и причины — `residual_scope.csv`, в том числе 29 envelopes, у которых runtime population/fallback остаются открытыми.

Повтор: Python с зависимостями `requirements.txt`, `python check_resolution.py --verify` из этой папки. Проверено на Python 3.12.14, pandas 2.2.3, numpy 2.3.5. Контроль включает schema/CSV, row count, ID coverage, отсутствие orphan output IDs, 8 legacy aliases/15 позиций и owner hashes. Это завершение адресного разбора, **не полный аудит**. Истинность source claims, вся transitive lineage и влияние на деньги/рейтинг остаются за пределами этой проверки.
