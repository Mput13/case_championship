# Идеи для дальнейшего решения кейса

Ниже восемь направлений, которые можно проверить на собранном контексте. Они не содержат выбранного города или обещанного финансового результата. Подробные формулы, предпосылки и первичные методические ссылки — в [семи методах после проверки Terra](../07_verification/terra_methods_data_review/usable_methods.md).

| Приоритет | Идея | Данные и проверка | Когда идея не подтверждается |
|---|---|---|---|
| P0 | Устойчивый топ-3 городов | Исправленный лонглист, пять групп критериев, swing/ROC, диапазоны данных и весов | Топ-3 зависит от неподтверждённого значения или малого допустимого изменения весов |
| P0 | Сравнение хаба и прямых рейсов при одном парке | Одни и те же ограничения, помашинные цепочки, обслуживание, ночёвки, перегоны | У выбранной сети невыполнимые обороты или скрыто больше самолётов |
| P0 | Карта условий преимущества хаба | Варьировать трансферный спрос, частоты, загрузку, выручку и стоимость базы; проверять места на обоих плечах | Выигрыш возникает только при неподтверждённом трансфере либо двойном счёте пассажиров |
| P0 | Расчёт без субсидии и порог поддержки | Проверенная редакция правил, договорные условия, затраты и доходы каждого маршрута | Предпочтение стратегии зависит от выплаты, на которую нет подтверждённого права |
| P1 | Отбор прямых пар по выигрышу поездки | Расписание, цена, время от двери до двери, поезд/авто, сезонность | Выигрыш исчезает при реальной частоте, времени доступа или цене |
| P1 | Запуск по этапам с условием перехода к хабу | Сначала ограниченная сеть, затем измеримые условия расширения: продажи, стыковки, регулярность | Пилот не позволяет проверить спрос будущей сети или требует основной части затрат заранее |
| P1 | Чистый прирост Red Wings после перетока | Базовая сеть и спрос, новая сеть, пассажиры и доходы по совместимым определениям | Рост новых линий преимущественно забирает собственных пассажиров без улучшения результата компании |
| P1 | Сеть без новых SJ-100 | Сценарий задержки поставки и диапазон фактически доступного парка | Выбранная схема существует только при гарантированной поставке, которой нет в источниках |

P0 — основа обязательного сравнения, P1 — полезное углубление. Это порядок исследования, не оценка трудозатрат или обещание готовности к конкретному дню. Доходность нельзя доказать без затрат; при их отсутствии показывать выручку отдельно и считать порог допустимых затрат.
