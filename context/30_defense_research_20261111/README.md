# Локальные материалы к очной защите Red Wings

Начните с [MORNING.md](MORNING.md): пять находок, их влияние и три действия команды. Предложение OMS сохраняется; это не доказательство полной прибыльности или разрешение запуска.

Все новые результаты находятся в этой папке. Коммитов, пушей, изменений панели и обращений к людям не было. 436 исходных tracked-файлов сохранены. Последняя модель на начало работы зафиксирована через GitHub connector на `0b0fbcb742ea2e54e05b80a5b8e890200fd5daae`; два обычных git fetch завершились ошибкой GnuTLS. Текущая локальная рабочая ветка не выдаётся за последнюю модель.

Две небольшие правки независимого review применены координатором только к новому пакету economics/: периоды сезонных сумм и пояснение агрегата расходов. Числа не изменены; исходное состояние сохранено в coordinator/before_metadata_fix/. Исторический review CHANGES не переписан задним числом. [Receipt исправлений](coordinator/post_review_fix_receipt.json) отделён от независимого заключения.

Воспроизведение расчёта в этой локальной рабочей копии:

```bash
PYTHONDONTWRITEBYTECODE=1 context/28_end_to_end_audit_20261110/code/sandbox/venv/bin/python context/30_defense_research_20261111/economics/verify.py
```

Команда реально выполнена после правок: 1502 проверки, ошибок 0. Окружение pandas/numpy переиспользовано из прежнего аудита. Новая установка не требуется. Исходные model inputs и их SHA/Git blobs — в model_schedule/replay_inputs_manifest.json; часть raw из прежнего аудита явно отмечена UNTRACKED_RAW_FROM_PRIOR_AUDIT и не является частью Git pin. Наличие хеша подтверждает точность снимка, а не истинность факта.

Первоначальный независимый код/actual checks находятся в review_final/: его 20 ожидаемых метаданных ошибок относятся к сохранённой версии до правки. Он не переобъявлен прошедшим проверку исправленной версии. Остальные адресные проверки — в review_evidence/ и review_costs/. Скрипты некоторых ролей перезаписывают собственные receipts при повторном запуске; сохранённые выводы и границы приведены отдельно.

Большой миллионный реестр и транспортные части не создавались. Для команды достаточно таблиц показателей, источников, допусков и условий. Старые рабочие материалы оставлены как свидетельства; источниковые выводы брать из завершённых review, а не из прежних непроверенных меток QUOTE или guessed buyer.
