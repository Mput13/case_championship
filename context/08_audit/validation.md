# Проверка пакета

Основной агент проверил файлы 7 ноября 2026 года.

- `python3 scripts/check_context.py`: структура CSV/JSON, уникальность ID, связи реестра и проверок, локальные Markdown-ссылки, пять SHA-256, происхождение чисел в реестре городов — PASS.
- `python3 scripts/build_source_registry.py`: 147 исходных записей, 134 URL, 84 карточки аудита; генерация без сети. Исходные утверждения и результаты проверки не смешаны.
- SHA-256 и размер всех пяти исходных файлов пользователя совпадают с начальным манифестом: исходники не изменены.
- Полные DOM, сообщения Telegram, экспорт Google-таблицы, оригиналы документов и сведения сессий исключены из Git. Проверен предназначенный для публикации состав.
- Основной агент повторно прочитал первичные публикации Red Wings, определения Finnair и итоги аэропортов Уфа, Курумоч и Красноярск. Проверки Terra содержат точные ссылки, периоды, ошибки доступа и неподтверждённые поля.

Сохранены исходные байты образцов с CRLF; это отражено в `.gitattributes`, чтобы форматирование не меняло хеши. Обрезанный XML из Flash намеренно оставлен как непригодный архивный артефакт; проверка не объявляет его валидным SDMX. Полный повтор сетевых выгрузок не выполнялся: источники динамические, а повторная загрузка может заменить снимок.

Проверка структуры не подтверждает экономический прогноз, OD-спрос, лицензии всех источников или эксплуатационную готовность сети. Пакет содержит достаточные указатели для продолжения исследования, а не готовую защиту кейса.
