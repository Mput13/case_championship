# Каталог источников и сбор данных

[source_registry.csv](source_registry.csv) объединяет **147 записей поиска**, соответствующих **134 различным URL** после минимальной нормализации. Это не 134 готовых датасета: здесь есть наборы, описания, документы, библиография и непроверенные ссылки. Города и отдельные фактические утверждения находятся в своих реестрах проверки.

Повторяющиеся URL связаны через `source_key` и [source_index.json](source_index.json). Источники не склеены в одну «проверенную» строку: одна и та же страница может поддерживать разные утверждения разных авторов. Параметры URL сохранены, потому что они могут определять документ или показатель. Разные URL одного документа могут остаться раздельными.

Результат независимого аудита — [source_reviews.csv](source_reviews.csv): **84 карточки проверки**, включая 13 дополнительных источников. `original_record_id` связывает их с исходным каталогом; пустое поле обозначает дополнительный источник. Пользоваться исходной строкой нужно вместе с соответствующей проверкой. Карточка с результатом `UNKNOWN`, `WRONG_INDICATOR` или `NOT_REVIEWED` не становится готовым датасетом из-за попадания в этот файл. Города, отдельные утверждения и новые образцы дополнительно собраны в [проверках](../07_verification/README.md).

## Поля реестра

| Поле | Смысл |
|---|---|
| `record_id`, `source_record_id` | Уникальная запись общего реестра и ID в исходном каталоге |
| `source_key`, `url` | Связь одинаковых URL и исходная ссылка |
| `category`, `title` | Раздел поиска и исходное название; название Flash может оказаться ошибочным |
| `verification_scope` | Кем и в каком объёме запись проверялась |
| `claimed_status` | Статус, заявленный автором исходной записи; не автоматически принятый итог проверки |
| `period`, `grain` | Период и единица наблюдения по исходной карточке |
| `useful_for`, `limitations` | Предложенное применение и ограничения; для Flash требуют сверки с замечаниями Terra |
| `license_claim` | Заявление об условиях, а не юридическое разрешение на все данные портала |
| `provenance` | Файл с исходной карточкой относительно `context/` |

`FLASH_CLAIM_REQUIRES_REVIEW` означает, что даже заявленные `VERIFIED_SOURCE` и `ACCESSED_SAMPLE` следует читать только вместе с результатом независимого аудита. `TERRA_CHECKED_SCOPE_SEE_REPORT` отсылает к конкретной проверке и её ограничениям; часть страниц прочитана через поисковую копию, часть файлов не получена. Статус чтения страницы не означает наличие лицензии, нужного покрытия или реальных OD-наблюдений.

Сводный реестр воспроизводится без сети командой `python3 scripts/build_source_registry.py` из корня проекта. Он намеренно сохраняет исходные формулировки: исправления находятся в `07_verification`, а рабочий отбор данных выполняется по проверенным карточкам.
