Это конкурирующий продукт, а не впервые открытый рынок. Каждая пересадка занимает два кресла, тариф один. LP учитывает вытеснение местных продаж. Полная экономика каждой строки сохраняет неизвестные: `ΔPnL = вклад + подписанная дельта остальной сети − K_ещё_не_учтённое`. Отрицательный Kmax означает дефицит ещё до базы/лизинга/запуска; положительный Kmax — только допустимый потолок таких расходов. Депозиты, инвестиции и сроки оплаты требуют отдельного cash-календаря. Поддержка не признана доходом. НДС/комиссии повторно не сняты с авторского net yield.

До окончательной сдачи остаются C33 на тех же опубликованных рейсах, датированные ротации фиксированных программ, адресные пробелы конкуренции, граница пересадочного эффекта ступеней OMS и совместимые маршрутные дельты для общей методики.
