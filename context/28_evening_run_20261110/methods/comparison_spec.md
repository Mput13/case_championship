## Единицы и совместимость

Ключ результата: `calendar/scenario/network/policy/cap`. В исходных `result` сохранены ноги и пересадки; `metrics` содержит поездки, сегменты, миграцию, полную билетную сумму до/после перетока, поддержку, переменные расходы и вклад. Все деньги — RUB за указанные модельные операционные недели; это не факт2027/2028. Один билет пересадки считается один раз; кресло расходуется на каждом плече. Direct `joint` уже ограничивает общий захват пары; старое исправление не повторяется.

`cap` включает авторский резерв1, блок-часовой лимит70 на рабочий борт в неделю. `aircraft_hour_lower_bound_including_reserve` — нижняя часовая оценка плюс резерв, не подтверждённое число доступных бортов или допустимое расписание. Для SJ100/ПД-8 параметры SSJ100 — аналог, не измеренные эксплуатационные затраты.

Полный signed delta: `ΔPnL = C + D_old_external + S_valid_additional − K_excluded`. В C уже находятся учтённые foregone tickets, flight/pax costs и выбранная сценарная поддержка. Повторять их нельзя. Для cancelled/replaced donor нужны отдельно прежние и новые поступления/избежанные расходы. Для нового самолёта альтернативное назначение отлично от снятого старого. Cash задаётся датами gross receipts/payments и финансирования, не знаком C.
