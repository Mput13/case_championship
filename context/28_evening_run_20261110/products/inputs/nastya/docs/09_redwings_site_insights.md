## Факты
- **Новый гендиректор с 30.10.2026 — Роман Чуев**: с 2010 руководил аэропортом Минводы; 2020–2026 — гендиректор кластера «Северный Кавказ» холдинга «Новапорт» (Минводы, Владикавказ, Ставрополь, Нальчик). Ивлиев был врио после ухода Лебедева, остаётся коммерческим директором.
- **Официальные приоритеты (стратегия акционеров)**: расширение сети; ввод новых российских самолётов (Red Wings — один из первых эксплуатантов); подготовка экипажей; приоритетные регионы — **Урал, ДФО, СКФО, ЮФО** + СНГ, Азия.
- **Место на рынке**: 5-е по международным перевозкам, 9-е по внутренним. ~25 тыс. рейсов в год, >1500 сотрудников, 30+ млн пассажиров за 27 лет.
- **Флот (официально)**: 28 ВС — 20 SSJ100 (100 мест, 4200 км), 3 Ту-214 (194 места, 5200 км), 2 Ту-204-100B (210 мест, 3800 км), 3 B777-200ER (412 мест, 9100 км). Red Wings — единственный коммерческий эксплуатант Ту-204/214; на них в H1 2026 рейсов +13%, пассажиров +8%, в июне 2026 — 30 тыс. пасс. (×2 к июню 2025).
- **Сеть и сезонность**: лето 2026 — 118 направлений (69 международных), «хаб-аэропорты» по формулировке компании: Москва, Санкт-Петербург, Казань, Самара, Екатеринбург, Минводы, Сочи, Махачкала. Зима 2026/27 — 71 направление (34 международных), хабы те же без Минвод. Почти 40% направлений летом сезонные.

Многие тонкие маршруты Red Wings — между аэропортами «Новапорта» (Чита — Кемерово, Томск — Улан-Удэ, Саранск…). Новый гендиректор — из «Новапорта». Это совпадение, а не доказанная связь.

## Зацепки и креативные идеи для кейса (рассуждения, требуют проверки данными)
1. **Выбор хаба в логике официальной стратегии**: приоритеты Урал/ДФО/СКФО/ЮФО и биография нового гендиректора (Минводы) → кандидаты из СКФО (Минводы, Махачкала) стоит включить в лонглист, но они же — зона «Ковра» и закрытий (май 2026). Честное противоречие «стратегия vs устойчивость» — хороший материал для анализа чувствительности.
2. **Red Wings уже «мультибазовый» перевозчик**: 7–8 «хабов» в формулировке компании. Значит, кейс можно переформулировать: не «открыть хаб с нуля», а «какой из существующих узлов превратить в настоящий стыковочный хаб (волны, гарантированные стыковки)» — Екатеринбург уже наполовину им является.
3. **Сезонность как ресурс для SJ-100**: летом 118 направлений, зимой 71 → зимой простаивают кресла. Идея: подбирать сеть SJ-100 так, чтобы зимние маршруты (горнолыжный Кузбасс, вахта, Израиль/Египет, ДФО) закрывали провал.
4. **«Цепочки» как третья модель между хабом и прямыми рейсами**: Нарьян-Мар → Махачкала → Сочи одним бортом. Похожая практика за рубежом — «milk run» (рейсы с промежуточными посадками, напр. на Аляске). Позволяет связать тонкие пары, которые поодиночке не наполнить.
5. **«Вахтовые коридоры»**: Казань → Нижневартовск/Новый Уренгой, Самара → Ханты-Мансийск (ночные вылеты). Стабильный круглогодичный спрос, возможны корпоративные контракты с нефтегазовыми компаниями (блоки мест). Компания сама не называет это вахтой — гипотеза.
6. **Мультимодальный «единый билет»** (самолёт + трансфер/автобус) уже есть для Шерегеша → масштабировать для хаба: охват городов без аэропорта в радиусе 2–3 часов от узла. Прямо попадает в тему чемпионата (сочетание видов транспорта).
7. **Региональные соглашения — готовый механизм** (Кузбасс 2026, Омск 2021): регион как партнёр хаба. Кузбасс → самое популярное направление — Екатеринбург: Кольцово уже работает как узел для Сибири.
8. **Программа лояльности — пробел**: в «крепостях» конкурентов лояльность — один из барьеров; без программы Red Wings слабее в борьбе за частых пассажиров. Идея: региональная/партнёрская программа (с регионом, аэропортом, Belavia).
9. **Партнёрство с аэропортовым холдингом**: гендиректор из «Новапорта», много маршрутов между его аэропортами → переговорная позиция по сборам и слотам для хаба/сети.
10. **Грузия/СНГ из регионов напрямую — доказанная сила** (100% загрузка Новосибирск — Батуми). Внутренний хаб может кормить эти международные рейсы (Сибирь → Екатеринбург → Тбилиси/Ташкент), но учитывать дальность SSJ (4200 км по сайту) и конкуренцию иностранцев на международке.
11. **Ту-204/214 — уникальный актив** (единственный эксплуатант): загруженные/дальние направления; SJ-100 — тонкие межрегиональные.
