## Поддержка: связанный тарифно-расходный сценарий

Проверен [порядок22-64160-00191-Р, версия7](https://old.favt.gov.ru/public/materials/0/3/9/e/7/039e77a7205ca81e3070590870e45a3e.pdf). Единица — выполненный eligible рейс; сумма зависит от договорной ставки в пределах таблицы и территориального коэффициента. Один маршрут имеет одного получателя. Пункт7а связывает договор с **предложением всех economy мест** по цене не выше специального тарифа минимум за5дней. Это не гарантия продажи мест. Отчёт/проверка/оплата происходят после выполнения; положительный начисленный результат не устраняет prefinancing.

Новая таблица `addendum_constrained_support_probes.csv` **сначала ограничивает воздушную выручку, затем** добавляет диагностический потолок за рейсы. Неизвестная будущая поддержка нигде не превращена в подтверждённый доход. 1 773 ₽/segment из автора не применялись и остаются только старым авторским сценарием.

Все 26 строк — **справочный опыт**: коэффициент1, исходный тариф приложения2 без ещё не подтверждённой региональной/арктической корректировки, без снижения предела по специальным условиям, при гипотетической оплате всех указанных рейсов по максимальной ставке. НДС отдельно повторно не вычитается: gross-тариф используется как щедрая верхняя граница воздушного поступления, не как доказанный net yield. Для PEE—RGK взяты самые высокие исходные distance bands как оптимистичный reference ceiling; этим не установлена протяжённость или eligibility пары. Территориальные множители, утверждённые надбавки, отбор, тип, seat count, эффективность, период, получатель и фактическая ставка требуют отдельного допуска. Поэтому эти числа нельзя называть юридическим универсальным cap или доходом 2027.

- **C10:** корпоративный блок и публичная продажа должны быть совместимы с условиями конкретной программы. Нельзя оставить высокий авиационный take-or-pay и сверху добавить весь grant. Для каждого1/2/4 режима сохранены limited-fare расчёты запуска и steady.

В условном бюджетном опыте поддержка относится к16 KVX—MRV плечам; доставочные SVX—KVX рейсы не признаны eligible. Высокую авиационную гарантию нельзя спрятать внутри санаторной цены. Неавиационная часть пакета и её договоры выделяются отдельно.
- **C17:** отсутствие поддержки в основном опыте сохранено. При100 летних пассажирах на рейс в2027, после справочного ограничения тарифа, требуется **49,31 / 122,96 млн ₽** поддержки до K. Это показывает, **какое финансирование и тарифные условия меняют вывод**, а не устанавливает грант. Без поддержки прежний проверенный сезонный рецепт не проходит. При70 летних пассажирах base не покрывается даже таким reference. Обещать прибыль по механизму1773×пассажиры нельзя.
- **C31:** отдельно показаны только4 добавочных OMS-плеча. Их старая программа RW не делает новую частоту eligible автоматически.
