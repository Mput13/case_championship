## Что меняет решение

- Субсидия рассматривается вместе с ограничением цены и правом на её получение. Условный положительный результат при прежней авторской поддержке не является подтверждённой прибылью сети.
- Для хаба проверяется расписание каждой пересадки. Укладка рейсов в часы самолётов сама по себе не обеспечивает пересадочные продажи; следующий общий расчёт включает эту проверку и вариант синхронизации на том же ресурсе.
- Сдвиг существующего рейса может не добавлять лётных часов, но лишать самолёт следующего задания. В расчёте C33 это отдельное условие стоимости изменения расписания.
- Для продуктовых предложений рассчитаны границы: требуемая гарантия, цена пакета, допустимая стоимость замены самолёта или партнёрского места. Они не заменяют договор и подтверждение свободного ресурса.
