# Финальная версия методики

Закреплён пакет [5512f7d](https://github.com/Mput13/case_championship/blob/5512f7d474a5db4bb658aae30b10f8b886629861/context/28_evening_run_20261110/methods/final_handoff.md). Он добавляет финальные метаданные и квалификации к проверенным расчётам. Текущий реестр приёмки — `final_acceptance.csv`; исторический `strategy/acceptance_register.csv` сохраняет прежние PENDING.

EV-MR03 относится к f99d6cd, EV-MR04 — к 9f0b5d2. Финальная упаковка не расширяет их допуск. Внешний рынок, свободный парк, фактическая поддержка, полный бюджет и решение команды остаются неподтверждёнными.

## Воспроизведение

Хеши проверяют полученный неизменяемый пакет. Повторные вычисления выполняются в отдельной временной копии, с сохранением оригиналов. EV-MR03 подтвердил семантическое совпадение всех расчётных CSV; у `runs/integer_year_v1/annual_market_caps.csv` порядок строк может зависеть от обхода множества. Эту таблицу после повтора сравнивают по ключам и значениям. Изменение её файлового хеша само по себе не означает изменение чисел. Frozen-таблицу не перезаписывают ради выравнивания порядка.

Это уточнение инструкции воспроизведения родителем, без изменения авторских файлов, расчётов или независимых вердиктов. Проверки передачи: [methods_freeze_checks.json](../../intake/methods_freeze_checks.json).
