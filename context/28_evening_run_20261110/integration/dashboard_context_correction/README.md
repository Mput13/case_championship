# Связь контекста KUF–SVX с C33

В сборке `5101302f` отсутствие связи пары с конкретной гипотезой ошибочно обозначено как отсутствие самой пары в реестре. KUF–SVX есть в Evidence `38f0`, но относится к C03. C33 содержит 16 программных строк этой пары и вместо доступных сведений получил одну ложную запись пробела. Дефект ROOT-DASH-01 независимо воспроизведён в текущем review; исходный пакет сохранён.

Для интеграции использовать **cards.json и route_context.json из этой папки**, остальные файлы — из [исходной поставки](../dashboard_handoff/5101302f/README.md). Удалена одна ложная запись, добавлены 34 явные связи C33 с уже имеющимися строками: публикациями, тарифными наблюдениями и ограничениями покрытия. Каждая связь сохраняет исходные `provenance` и `source_fields`, получает `original_evidence_record_id` и отдельный `association_id`. Это повторное использование свидетельства, не новые вылеты: при подсчёте рынка нужно исключать дубли по исходному record ID/источнику. Исходные 85 связей в route_links.csv не меняются; дополнительная связь описана в context_patch.json.

Даты 2026 года не становятся расписанием 2027–2028. Не меняются численные показатели карточек, цены, частоты, конфликты часов, полнота рынка и допуски. TLV–ZIA и SVX–ZIA действительно отсутствуют в данном реестре и остаются пробелами. Исходный CHANGES не заменяется приёмкой исправления.

`python3 build.py --verify` повторяет проекцию по exact Git blobs без записи. Проверены исходные поля, отсутствие изменений всех десяти наборов метрик, сохранность девяти других карточек, два действительных пробела, повторное применение без размножения строк и отказ при дублировании ID. Независимый recheck исправления пока PENDING. Применение к UI Насти не выполнялось.
