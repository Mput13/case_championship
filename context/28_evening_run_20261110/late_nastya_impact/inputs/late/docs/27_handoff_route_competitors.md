# 27. Задание на сбор данных: кто летает на каждой паре сети

Для Миши. Срез 10.11.2026, вечер. Ветка `шаг-1`.

## Зачем

На панели под картой «Итоговая сеть» есть таблица маршрутов. В ней столбец «Как летят сейчас и кто летает»:
- **как летят** — уже заполнено для всех пар: «прямой рейс есть», «с пересадкой в городе X» или «сейчас авиамаршрута нет» (модель поездок, `data/processed/od_pairs.csv`);
- **кто летает и сколько раз в неделю** — заполнено только там, где есть расписание на 7–13.12.2026: карточки маршрутов (`data/external/colleagues/route_product_cards.csv`) и табло аэропорта Омск (`omsk_outbound_week_20261207.csv`). По остальным парам пусто.

Чтобы видеть конкурента на каждом луче любого хаба, нужен один файл.

## Что собрать

Файл `data/manual/route_competitors.csv` (заголовок уже лежит в репозитории). Одна строка — один перевозчик на одной паре.

| Колонка | Что писать | Пример |
|---|---|---|
| a, b | коды аэропортов IATA, порядок любой; Москву писать `MOW` или код аэропорта | OMS, IKT |
| carrier | перевозчик как в расписании; названия сводятся через `data/manual/carrier_names.csv` (добавь строку, если нового нет) | S7 |
| flights_week_each_way | рейсов в неделю в одну сторону | 2 |
| via | пусто для прямого рейса; код города пересадки для стыковки одного перевозчика | OVB |
| period | неделя или сезон, к которому относится расписание | 2026-12-07/13 |
| source_url | ссылка на источник | https://… |
| checked_at | дата проверки | 2026-11-11 |

Какие пары нужны: `data/manual/route_competitors_todo.csv`. Его пересобирает `src/build_dashboard.py`; в нём все пары всех сетей панели (20 хабов и прямые треугольники), по которым перевозчиков пока нет, и как летят сейчас.

Если нет прямого рейса, полезно записать лучшую стыковку: перевозчик, город пересадки в `via` и частоту. Тогда в таблице будет видно, через кого сейчас летят пассажиры этой пары.

## Где взять

1. **API Яндекс Расписаний** — перевозчики и частоты по паре. Нужен ключ: положить в `.env` как `YANDEX_RASP_KEY`, в код и git ключ не класть.
2. **Табло и расписания аэропортов** (как сделано для Омска): сезонное расписание в PDF или на сайте.
3. **Сайты перевозчиков**: карта маршрутов, расписание на неделю.

Не брать цифры из чужих сводок без ссылки на первичный источник.

## Что будет после

Положил файл → `py -3.13 src/update.py` → в таблице маршрутов появятся перевозчики и частоты по каждой паре. Код править не нужно. Если файл пустой, панель показывает то, что есть сейчас.

Дальше можно сделать (не сделано): учесть частоты конкурентов из файла в доле рынка пары. Сейчас модель оценивает частоту конкурентов по потоку на рейсе (`src/network_model.py`, функция `leg_share`).

## Что уже сделано по проверкам Миши

- **Проверка 1 (отбор пропускает лучшую сеть).** Подтвердилась: при лимите 10 самолётов отбор собирал для Омска сеть хуже (−367 млн ₽), чем при лимите 4 (−186). Теперь сеть каждого варианта собирается при лимитах 4, 6, 8 и 10 самолётов, и берётся лучшая из тех, где не меньше 8 маршрутов (`search_caps`, `hub_best`, `direct_best` в `src/network_model.py`; параметры `fleet_search_min`, `fleet_search_step`). Прямая сеть перебирается так же.
- **Проверка 4 (самолёты по этапам).** Пока сделано шагами по числу самолётов (`fleet_ramp.csv`); календаря поставок нет — см. строку про `deliveries.csv`.
- **Метки на панели.** Блоки, которые меняются от города на табло, и общие выводы помечены по-разному.
