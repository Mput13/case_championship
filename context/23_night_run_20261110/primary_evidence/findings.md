### Расхождения

У KUF и закреплённого SVX для12ключей опубликованных рейсов различаются часы на5–10мин. Частоту повторных публикаций не складывать; для точной стыковки соответствующие часы имеют `CONFLICT_HOLD`. Новый снимок не исправляет старый frozen-run задним числом. Разницу необходимо разрешить новым согласованным input_set либо явно удержать как неопределённость времени.

Уфимские правила содержат8несогласованных длительностей для разовых KUF-продуктов вне целевой недели. Сохранены исходные и вычисленные по часовым поясам минуты, без выбора удобной версии. Эти строки не попали в целевую неделю. Все семь названий дней есть в HTML каждого правила, но операция отмечена только `_active`; счёт всех семи дал бы ложную частоту. `FROM` — вУфу, `TO` — изУфы, что проверено по flight829/830 и источнику.

### Наземные и пересадочные альтернативы

[Самарская ППК](https://samppk.ru/all-news/company-news/zapushcheno-pryamoe-skorostnoe-soobshchenie-samara-ufa-samara/) публикует «Ласточку» Самара–Уфа,6ч28мин, по пятницам/выходным туда и по субботам/воскресеньям обратно. У страницы есть расхождение индексной даты с текстом о начатом мае; декабрьская применимость и цена не проверены. Поэтому `ground_alternatives.csv` хранит исторический продукт и часы, но **не** недельную частоту7–13декабря. Отдельные августовские отмены не распространяются на декабрь. Для выбора города следует сравнивать поездку между центрами и полное время через аэропорты; доступ к аэропорту, багаж и цена остаются неизвестными.

Для конечных OD черезUFA конкурируют прямой продукт, перелёт с посадкой, пересадка черезSVX/MOW/другой узел, наземная поездка и отказ от поездки. Наличие двух рейсов на карте не доказывает продаваемую стыковку: нужны конкретные даты обоих плеч, MCT, правила багажа, защита и один сквозной тариф. Здесь не создано ни одного неподтверждённого гарантированного connecting product. В частности, старый кодшеринг2024 не становится продуктом2026.

Частоты/кресла не калибруют capture. Все конкурирующие программы должны делить один конечный OD-пул; местный пассажир и пересадочный на одном плече используют общие кресла. Перенос с собственногоRW не новая поездка компании. Пакет передаёт данные для проверки порогов модели, не новый прогноз перехвата.
