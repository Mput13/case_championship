В этой отдельной проекции момент равен `scenario_definitions.period_start UTC + absolute minutes`. Исходный пакет, raw, сценарные ставки и продажи неизменны; минимальная замена функции и все входы закреплены кодом/хешами `build.py`.

Все 40 строк арифметики опубликованного эпизода первого дня совпали до применения ограничений на вывод. Это не независимое одобрение расходов/денег, а проверка численной дельты этой правки.
