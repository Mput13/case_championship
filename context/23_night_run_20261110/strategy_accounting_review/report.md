## Относительный бюджет

Из собственных contribution получены 12 попарных неравенств. Для A против B условие имеет вид:

`(n_A−n_B)·F + (b_A−b_B)·B + (O_A−O_B) ≤ C_A−C_B`.

Здесь n — дополнительно оплачиваемые рабочие/резервные борта в этой постановке, b — новая база UFA. Уже неизбежные расходы не становятся incremental от распределения бухгалтерского F. Для совместного набора применяется `C_joint−n_additional·F−B_once−O_joint`; источник будущего парка и alternative/donor не подставляются нулями.

При равных O и одинаковых дополнительных ставках F,B≥0:

- Base H4 выше D_previous_best8 при **B<400 166,279868**.
- Base H4 выше D_SVX8 при **F+B<2 703 326,676013**.
- Base D_previous_best8 выше D_SVX8 при **F<2 303 160,396145**.
- Cautious D_previous_best8 выше D_SVX8 при **F<3 319 608,301786** и доминирует H4/H8 в этой ограниченной денежной постановке.
- H8 уступает D_previous_best8 в обоих сценариях при этих одинаковых расходах и других равных условиях.

Все 60 исходных contributions отрицательны ещё до дополнительных статей. Условия сравнивают величину условных потерь. `KEEP=0` означает разность действия с самим собой; прибыль компании UNKNOWN. Именованный donor-state comparison остаётся необходимым. Повторное вычитание его выручки и той же маржи недопустимо. Никакой маршрутный победитель или launch recommendation здесь не назначен.
