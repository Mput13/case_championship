# Сопоставление на одинаковой программе рейсов

Пакет `methods-common-v3`. Контролируемый опыт выполнен на датированных программах Цири **context21**, неделя 7–13 декабря 2026 года. Меняется только рецепт сценарного спроса; рейсы, кресла, тарифы, собственная каннибализация, расходы и порядок распределения сохраняются. Это `COMMON_COMPARISON / AGENT_PROPOSAL`, независимая проверка нового опыта **pending**. Ни одна стратегия не получила статус принятой командой или разрешённой к запуску.

## Результат общего опыта

`C` — недельные направленные bands из context21. `N` — численный годовой масштаб пары из `Demand.get` Анастасии, делённый на 2 направления и 52 недели. В cautious тоже использовано 52: это явно заданная общая конверсия, а не авторская годовая модель с 48 рабочими неделями. `N` не устанавливает зимний конечный OD: исходная величина может быть модельным сегментным proxy или более широким опубликованным потоком. Пересчёт единиц не устраняет эту неопределённость.

Все деньги ниже — **млн RUB за неделю, вклад до базы, парка и альтернативы ресурса**, в ценовом/налоговом сценарии Цири. Годовые деньги модели Анастасии в эту таблицу не перенесены.

| Программа | C base | N base | C cautious | N cautious |
|---|---:|---:|---:|---:|
| D_SVX8 | −7.326 | −2.165 | −17.737 | −13.849 |
| H_UFA_4 | −4.623 | −2.975 | −15.163 | −13.132 |
| H_UFA_8 | −9.497 | −5.958 | −28.166 | −25.092 |

В base порядок D_SVX8 и H_UFA_4 меняется. При линейной смеси `D(α)=(1−α)C+αN` равенство наступает при **α=0.68350900199**, вклад обеих программ **−3 168 101.77 RUB/неделю**. α — координата между двумя рецептами, не вероятность, измеренная сезонность или установленная доля конечных пассажиров. Эта граница показывает зависимость ранжирования от входа; она не выбирает правильный рецепт. Для cautious пересечения этих двух программ на α∈[0,1] нет: H_UFA_4 имеет меньший условный убыток.

При C base H_UFA_4 превосходит D_SVX8 по вкладу на **2 703 326.68 RUB/неделю**. У H_UFA_4 на один рабочий борт больше и новая база. При одинаковой стоимости дополнительного борта F преимущество полного бюджета требует `F+B+(O_H−O_D)<2 703 326.68`. При N base D_SVX8 уже имеет преимущество **809 244.10 RUB/неделю** до этих статей. Изменение рецепта и изменение полного бюджета — отдельные причины смены порядка.

Из восьми исходных context21 итогов проверены все восемь. Общий опыт включает три программы, поскольку у D_previous_best8 **шесть пар с ZIA отсутствуют** в матрице Анастасии. Отождествление MOW и ZIA не выполнено; кандидат остаётся в исходном и бюджетном сравнении. Отсутствие входа не заменено нулевым спросом или плохой оценкой кандидата.

## Границы по объёму

Для каждого рецепта спрос всех его рынков умножался на один неотрицательный коэффициент t. Порядок local-first и все остальные условия неизменны. Рассчитаны все 151 линейный участок для 18 кривых: 12 масштабирований и 6 смесей C→N. На каждом участке желаемый спрос, остатки кресел, собственная миграция и вклад линейны; следующий участок начинается в ближайшем пересечении ветвей `min`. Значения в начале, середине и конце участков повторены численным симулятором: **453 проверки**, плюс проверка постоянного продолжения после заполнения всех локальных кресел.

| Программа, base | Первый нулевой вклад при t·C | При t·N | Вклад при всех локальных креслах, млн RUB/нед. |
|---|---:|---:|---:|
| D_SVX8 | Не достигается | Не достигается | −0.450 |
| H_UFA_4 | 2.4617708804 | 2.2064414956 | +3.175 |
| H_UFA_8 | 2.9194370052 | 2.0116807077 | +5.643 |

Это условия внутри фиксированного правила, а не оценки необходимого прироста реального рынка. При насыщении локальных кресел пересадочных пассажиров не остаётся: прибавление одной условной категории может вытеснять другую. Для D_SVX8 сохранённая собственная каннибализация оставляет отрицательный вклад даже при заполнении всех кресел. В бюджетном v2 граница этой программы была положительной в base, поскольку там каннибализация специально снята для оптимистической верхней оценки; результаты отвечают на разные вопросы и не противоречат друг другу.

В cautious максимум при сохранённых правилах отрицателен: D_SVX8 **−11.242 млн**, H_UFA_4 **−6.787 млн**, H_UFA_8 **−12.896 млн RUB/неделю**. Более сильное для исключения «только добавим спрос» доказательство из v2 сохраняется: даже после снятия собственной миграции фиксированные cautious расходы и тарифы дают отрицательную верхнюю границу. Это ограничение конкретных программ, не всех возможных сетей и не будущего парка.

Положительные +3.175/+5.643 млн — верхние возможности данного правила при полном заполнении локальных кресел, до неизвестных дополнительных статей. Они не являются доступными деньгами. Если `3F+B+O≥3.175 млн` для H_UFA_4 либо `5F+B+O≥5.643 млн` для H_UFA_8, положительного полного результата нет даже в этом насыщенном base-сценарии при одинаковой трактовке дополнительного резерва. Донорский бюджет и календарь финансирования требуют отдельных данных.

## Адаптер и первичные свидетельства

`runs/adapter_v1/table_mapping.csv` использует существующие 13 таблиц model_repair@27740ffe. Для Цири основной вариант — context21, **224 itinerary**. Data_bridge@abc09bbb сохраняется отдельной ветвью conditional16 с **860 itinerary**. Имя H_UFA_4 не является достаточным ключом: обязательны source SHA, input_set, variant, profile, run, scenario и candidate. В context21 H_UFA_4 содержит GSV/MRV/NJC/OMS; RELAXED-вариант с GOJ вместо MRV не подменяет его.

В money_ledger model_repair у 160 строк расходов рейсов не заполнена часть контекстных полей. Наш адаптер восстанавливает их только через **единственное совпадение полного ключа физического модельного рейса**, затем соответствующий context21 summary. Суммы не меняются. Исходная таблица сохранена; отдельные `qualified_money_ledger.csv` и `money_metadata_lineage.csv` показывают проекцию и происхождение каждого заполнения.

Выполнены равенство полного набора flight/capacity IDs, уникальность, существование каждого использованного плеча, связность itinerary, расход кресел, один сквозной тариф, одна стоимость рейса и денежная сверка. Отдельно повторена формула стоимости **160 сценарных строк рейсов** по неизменённым ставкам автора и их сумма по восьми программам/сценариям. Четыре синтетические порчи нового адаптера — пропущенное плечо, дубль плеча, сдвиг стоимости и дубль расхода — отвергаются. Это закрывает требуемое для нового адаптера покрытие MR05-N01; исторический checker v1 сохраняет свой узкий scope.

Первичный пакет @17b4f348 соединён с **фактически экспортированными конечными рынками**, а не со всеми возможными парами листьев:

Ни один из этих фактов автоматически не изменяет тариф, спрос или время модельного рейса.

## Статус проверок и решений

- MR05@b0b0830b сохраняет **CHANGES на exact344f4425**. Переименование 20/18 в модельные endpoint-пары выполнено в current projection2a74 и узко закрыто координатором; legacy v1 label удержан. Исходный verdict не переписан.
- MR05 независимо подтвердил MOW–OMS, восемь итогов Цири, C01 и десять контрпримеров. Он не проверял новый опыт или budgetv2.
- MR07 проверяет exact2a74; review model_repair и source/join переданы координатором отдельно. Новая собственная проверка v3 не объявляется независимой.
- Для Анастасии D-only guard не меняет текущие результаты. Величина превышения proposed Q(F) не является превышением всего рынка D. `common_market_bounds.csv` хранит оба определения отдельно; неоднозначное `pool_excess_annual` не используется как доказательство D-breach.
- Радиус 0/300/500/800 остаётся OPEN_DECISION. Суммы score разных составов городов не используются. Широкие гипотезы и полезные новые данные продолжают параллельную очередь MR04; их отсутствие в данном опыте не означает отклонение.
