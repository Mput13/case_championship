7 бинарных предикатов Definition of Done

P1
Скрининг: ≥50 орг. (7 секторов), 100% со статусом Go/Cond/No-Go и URL; 100% No-Go в why_not_registry.md.
P2
Трек B: ≥8 кейсов (≥4 РФ + ≥4 мир, вкл. провал и срочный ad-hoc) + 6 поправок РФ + 4–5 термшитов.
P3
Граф и ивенты: 100% Go + поставщики + проекты со спадом + ≥10 форумов; 0 склеек MOW, 0 ранних фильтров SSJ.
P4
Объём и Gap: ≥20 пар — когорты Min/Base/Max, бизнес-класс, авиа/ЖД, пулинг, узлы (SVX), закрыт Issue #5.
P5
Флот и экономика: ранжирование → потребный парк; ≥5 кластеров + ≥2 пилота (TCT + порог RW); 0 скрытых нулей.
P6
Ревью: PASS от обоих ревьюеров, 0 открытых blocker, зафиксированы Act On ≤ 5 и Dismissed.
P7
Комплект эксперту: HTML-досье (0 JS-ошибок), XLSX (0 ошибок формул), 1-стр. Memo (5 вопросов RW) + таблица оценок /10.

5 стоп-клапанов (по tstack + pstack)

1. Потолок 3 раунда Консула: Раунд 0 → 1 → 2 (+ макс. 1 бинарный P0-sign-off). Новые темы после Раунда 2 запрещены.
2. Ранний стоп по nit: только nit → фикс-раунд не запускаем; Act On ≤ 5, P2 уходит в Dismissed / бэклог.
3. Автомат Stuck (2 прогона): 2 итерации без прогресса или затянувшийся спор → стоп, 2–3 строки обеих позиций пользователю. Конец бюджета ≠ одобрение.
4. EXTERNAL-BLOCKED: нет данных в открытом доступе (ставки RW, ЕИС) → 1 попытка → [NEEDS-RW-DATA], без повторных поисков.
5. Grounded, но не bulk: Консул сам читает нужные файлы и делает точечные проверки, но массовый скрейпинг делает только terra.
