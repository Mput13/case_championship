Первый checkpoint: [flight_rules](normalized/flight_rules.csv), [датированные плановые рейсы](normalized/dated_flights.csv), [извлечённые ячейки](normalized/flight_rule_cells.csv), [flight manifest](flight_checkpoint_manifest.json). Официальный аэропорт Победилово сейчас публикует Mon/Thu; прежнее объявление Mon/Fri сохранено отдельной версией. Время в новом источнике прямо обозначено местным. Выезды07Dec20:50→08Dec00:20 и10Dec23:20→11Dec02:15; day offset получен из перехода часов при явном допущении длительности менее24ч. Это рекламные правила, развёрнутые на даты, не performed instances и не подтверждённые места. Остановки и фактический оператор конкретного вылета не проверены; ассоциация Азимут опубликована.

Фактическая booked check-in date UNKNOWN; arrival date не подменяет договорную дату заезда.
