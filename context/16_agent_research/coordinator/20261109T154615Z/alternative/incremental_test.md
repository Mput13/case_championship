# Проверка полезности сезонности для C14

Статус: NOT_RUN, NO_LABELS. Данные размещения не установили конечный OD, вид транспорта, уникальные поездки, платёжеспособность или причинный эффект пакета. Текущая проверка календаря полезна для задания конкретного продаваемого продукта; её наличие не доказывает преимущество прогноза.

Будущий тест фиксируется до появления результатов:

1. Единица исхода: оплаченная направленная конечная поездка KVX↔MRV по дате вылета, затем отдельно покупка пакета санатория и факт возврата. Дедупликация сегментов и повторных размещений; собственная каннибализация отдельна. Для теста продукта нужны агрегаты предложений, показов и покупок без персональных данных, цена/багаж/время/наличие мест и источник прироста.
2. База: одинаковые калиброванные годовой OD, тариф, доступность продукта и кресла; обычные население/аэропортовый поток не пересчитывать из санаторного ряда. Вариант A — плоский либо доступный на момент решения обычный сезонный календарь. Вариант B — форма 62074 соответствующего охвата при неизменном годовом масштабе. Вариант C — 62073. Ночёвки62302 исключить из основного теста из-за конфликта метаданных; добавить только отдельной чувствительностью.
3. Вневыборочная проверка — следующий заранее отложенный сезон/месяцы. Снимок ЕМИСС2026 может содержать позднейшие пересмотры2023–2025: без архивных vintages нельзя называть его историческим прогнозом, известным в2024. Честный проспективный тест начинается с закрепления нынешнего snapshot. Нет меток покупки/OD — не считать качество по самому объёму размещения.
4. Метрики: ошибка по направлению/месяцу и калибровка предсказанных агрегатов на фактических оплаченных поездках; отдельно изменение добавочного вклада при одном бюджете ресурсов/цене, без смешения с гостиничным оборотом. Результаты публикуются и при ухудшении. Coverage санаториев68/85 не заменять нулями в остальных территориях.
5. Отрицательные контроли: наземные и местные размещения не должны давать «воздушный OD»; календарь региона не должен улучшать произвольную пару из другого региона. Одинаковые рейсы/цены без санаторного признака и без связи с площадками сохраняются как ablation. Следить за конкурентом и за сменой методики2026; не выбирать месяцы постфактум ради победы модели.

Для C10 корпоративный слой имеет другой механизм и требует собственных меток реальных командировок/договоров. Число вакансий, площадок и национальный запас вахтовиков не используются для «валидации» санаторного продукта.
