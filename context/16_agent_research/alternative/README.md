# Дополнительные сырые данные Red Wings

Первый существенный срез роли `alternative`. [Выводы](findings.md), [карточки сигналов](signal_cards.csv), [покрытие](coverage.csv), [план объединения и команды](integration_plan.md).

Raw и collectors сохранены в этом каталоге и подпапках `modules/`. [Манифест источников](dataset_manifest.json), [реестр](source_registry.csv), [инвентарь байтов](file_inventory.json), [проверки](verification.json), [ограничения и недоступное](rejected_or_unavailable.csv). Манифесты описывают получение и преобразование, не утверждают рыночную точность.

- Размещение: первичные ЕМИСС и зеркала одного происхождения; 17 694 числовые ячейки, 85 региональных компонент. Месячные приращения и сезонные доли — DERIVED. Нет происхождения туриста или вида транспорта.
- Корпоративные связи: 46 площадок СИБУРа; 12 групповых наблюдений Газпрома; исторический search-index пример Игарки отдельно. Нет текущего корпоративного OD.
- Погода: 83 архива 2024, 519 366 станция-часов. [Реальный join](normalized/join_airport_weather_month.csv) с обычным OurAirports: 74 совпавшие станции, 9 NULL, без размножения строк. [Независимая проверка](modules/weather_review/review.md).
- Telegram: original сохранён с `PARSER_CONTAMINATION`; два примера воспроизведены. [Ремонт и его полнота](modules/telegram_correction/coverage.json) отдельные, пересчёт событий в этом срезе NOT_RUN. Старые производные в `quarantine/` отозваны.

Источник: LEAD / ACCESS_FAILED / ACQUIRED_RAW / PARSED / VALIDATED / RESTRICTED_USE. Значение: OBSERVED / DERIVED / MODEL_ESTIMATE / SCENARIO / UNKNOWN. Эти оси не взаимозаменяемы. Пустая числовая ячейка — NULL, причина хранится в покрытии/статусе; отсутствие записи не нулевой спрос.

Для CSV нужны UTF-8 и точные ключи, для `*.csv.gz` — gzip перед чтением. Даты получения — UTC, погода — UTC месяц. Никакие данные не объявлены оценкой пассажиров, выручки, доли RW или техническим допуском. Лицензии UNKNOWN там, где первичный текст условий не установлен. Публикация на открытом сайте не подменяет отдельную лицензию.
