# Передача исправленных тел

1. Сначала читать `coverage.json`, `verification.json`, `resume.json`; статус PARTIAL обязателен в производных материалах.
2. Вход тел — `normalized/main_posts.csv`, ключ `id`. Использовать `text` только при `body_status=MAIN_TEXT_RECOVERED` и `value_type=OBSERVED`. UNKNOWN остаётся NULL. `reply_preview_text` никогда не подставляется как тело.
3. Для исходного корпуса фильтровать `in_original_csv=True`. Полный целочисленный диапазон не равен множеству существовавших постов.
4. `source_page_sha256` ссылается на `uncompressed_sha256` в dataset_manifest; raw_path может быть gzip, для его целостности проверять `sha256` сжатых байтов.
5. Событие необходимо связывать с конкретным фрагментом и аэропортом. Mixed 4685 нельзя размечать одним lift-флагом для всех аэропортов; неопределённые случаи оставлять UNKNOWN.
6. Восстановление и семантическое извлечение — разные операции. В этом модуле не выполнены полный пересчёт событий, operating intervals или рейтинг. Исходная contamination и старые derivatives остаются карантином parent.
7. Обновление после текущего среза требует новой явной границы страниц/времени; команда resume сохраняет кеш и не запускает сеть при offline replay.
