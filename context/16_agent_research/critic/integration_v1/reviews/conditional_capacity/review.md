# Условные ограничения денежных порогов

Собственный `check_conditional_capacity.py` использует явный продукт C01 из pinned eac4 и опубликованный механический пример кресел. Числа полностью SCENARIO, не калибровка локальных продаж. Автор уже называет свой gate nominal upper bound; новый дефект арифметики не заявляется.

При f8000RUB за one-way journey, пассажирских расходах500RUB и постоянном остаточном разрыве500000RUB нужно34 продажи на направление. Они дают68 one-way journeys/136 посадок на четырёх плечах, вклад после заданного разрыва+10000RUB. Если на каждом плече сохранены80 кресел других продуктов, нагрузка114 превышает100. При доступных20 креслах вклад−200000RUB; условный тариф безубыточности13000RUB. Это показывает, почему номинальный денежный порог требуется соединять с остаточными креслами по всем плечам и с ценой потери локальных продаж. Реальные reserves/gap/fare UNKNOWN.
