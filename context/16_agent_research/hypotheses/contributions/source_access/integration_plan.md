# Включение в общий пакет

- Добавить девять записей source_registry и соответствующие raw/receipts через собственные SA00–SA08 ID; не объединять их с исходным OD.
- `observations.csv` — узкие факты для полей evidence/unknowns/test кандидата. Автоматически не превращать их в веса, объём спроса или net fare.
- `normalized/flight_board_sample.csv` — три датированных instance для проверки новизны кандидата; сопоставить IATA через D01 и оператора через D05. Не масштабировать три наблюдения в годовое расписание.
- SA03 и SA04 относятся к одной корпоративной программе. Два участника подтверждают её существование, но это не две независимые оценки спроса.
- SA01 и SA02 разделены по периоду. Дни и времена 2024 не подставлять в поездку 2026; не считать изменение дней доказанным непрерывным ростом частоты.
- SA05 хранить в исторических аналогах D26/D30. Права, условия и бюджет поддержки на 2027/2028 остаются отдельным D14/D29.
- Санаторный механизм относится к специальному локальному модулю D22/D27/D28. Отсутствие аналогичного источника для другой территории — UNKNOWN, а не нулевой потенциал.
