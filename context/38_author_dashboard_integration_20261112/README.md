# Дашборд в авторском дизайне

Открыть [redwings_panel.html](redwings_panel.html) или [dashboard.html](dashboard.html).

Использован целиком опубликованный дашборд kiruha355 из commit `6cbe817320f75db9823984e7c4eeb6091fd7d996`: исходные CSS, компоновка, табло, пульт весов, талон города, карты и четыре вкладки. CSS, каркас и тема P15 сюда не переносились. Исходный HTML сохранён отдельно; ссылка «Дашборд 1» открывает исходную версию 1.

В существующем авторском компоненте помесячной модели подключены девять принятых программ P09 и два сценария каждой. Новый раздел использует компоненты и типографику автора. Полные результаты передаются прежними gzip-пакетами без изменения значений. Декомпрессия, выбор и форматирование для экрана не пересчитывают спрос, экономику или финансирование.

Исходная годовая модель команды сохранена отдельно внутри вкладки сети: её цифры не смешиваются с дельтой 2027–2028. Добавлены все 2274 строки опубликованных предложений P02; это не inventory и не доказанные будущие кресла.

Стратегия исправлена: Омск, Самара, Челябинск и Тюмень — альтернативы размещения ресурса, а не рассчитанная очередь открытия четырёх хабов. Совместная экономика такой очереди не установлена. Старый показатель +503 млн ₽ не переименован в подтверждённую прибыль и не складывается с P09.

P09: exact `736859fdd08448c2564b7b9269b751abe00b5cbc`, manifest `7b20a1a247ee4b3cf96d94648bb36d61482cb0a58eb7a296ada49a78c818d1fa`. Приёмка — условный вычислительный research release, `APPROVE_WITH_EXPLICIT_LIMITS`. Наблюдённый конечный OD, полная прибыль, финансирование, реальные слоты, crew/ТО и срок №2 не установлены.

Сборка: `python3 -B context/38_author_dashboard_integration_20261112/build.py`. Проверка: `python3 -B context/38_author_dashboard_integration_20261112/verify.py`.

HTML воспроизводит авторскую зависимость от CDN D3. Локальный файл открывается в Chrome. T3 `preview_open` не принимает протокол `file://`; это ограничение протокола, а не причина менять авторский интерфейс или запускать сервер.
