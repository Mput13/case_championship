# Локальная демонстрация Travel Assistant

Адрес: `http://127.0.0.1:3080`. Процесс слушает только этот Mac. Пользователь выбрал локальный прототип; внешнего URL нет.

Прототип находится в `apps/red-wings-travel-assistant/`, инструкция запуска — его README. Активный запуск использует Pi 1.5.2, `deepseek-v4.1-flash` через МАИ и сохранённое расписание. Ключ читается из защищённого файла T3, в репозитории его нет. Технический предел — 20 модельных вызовов за время жизни запущенного процесса, по два на объяснение плана; при исчерпании карточки расписания сохраняются.

## Что показать

1. **Самара → Екатеринбург, 8 декабря 2026.** Выбрать готовый пример и нажать поиск. WZ 1034: 08:00 Самара (UTC+4) → 10:40 Екатеринбург (UTC+5), 100 минут авиаучастка. Время всей поездки и стоимость неизвестны. Показать навигационные ссылки по обе стороны аэропортов.
2. **Другие вылеты.** Для той же пары задать 8–11 декабря. В снимке два варианта; 9–10 декабря не покрыты, что отражается в результате. Это не полный календарь продаж.
3. **«Уже есть рейс».** Готовый пример WZ 1034 на 8 декабря. Номер/дата закреплены. В «Уточнить адреса» ввести адрес в Самаре либо Екатеринбурге и показать изменённую ссылку на карты. Адрес не меняет расписание и не подтверждает время дороги.
4. **Граница покрытия.** Нижний Тагил вместо города назначения даёт недостаток данных. Казань → Уфа на 8 декабря не находит прямого RW в проверенном покрытии. Это разные ответы, не утверждения об отсутствии любых способов поездки.

## Как описать результат

«Ассистент помогает выбрать рейс Red Wings и собрать дорогу вокруг него. Здесь показаны сохранённые данные. Следующее подключение — датированные поезд/автобус и городской маршрут; после этого можно проверять всю цепочку и сравнивать варианты по времени».

Не говорить, что уже работают полный мультимодальный поиск, актуальные цены/места, единая корзина, страховка или публикация. Встроенный HTML-просмотр содержит сохранённые ответы и не вызывает модель; полноценный локальный HTTP-прототип обращается к DeepSeek.

## Проверки

- 31 offline-проверка: доменная логика, HTTP, происхождение, лимиты, Pi tools и неполные данные.
- Настоящий Pi tool loop: 2 HTTP POST, 1 инструмент, нормальное окончание.
- Локальный HTTP → план → Pi → МАИ: 2 HTTP POST модели, 2 разрешённых инструмента, нормальное окончание; UI отдаётся, `.env` не отдаётся.
- Всего в трёх проверках МАИ наблюдалось 5 генерационных запросов и 2196 токенов по полученным usage. Денежный тариф неизвестен. TLS-ошибки до отправки ключа и ошибка локального импорта не были генерационными запросами.
- HTML-render: 1280, 728, 390 px. Настоящий браузерный E2E, live-транспорт, Docker и deployment не выполнялись.

Исследования и решения — в `decision.md` и `research/`; receipts — в `receipts/`. Исходные независимые исследования не переписывались после проверки координатора.
