## Как читать статусы

- `VERIFIED_SOURCE`: прочитанная страница поддерживает конкретное утверждение. Это не гарантия, что весь портал проверен или данные доступны для скачивания.
- `ACCESSED_SAMPLE`: получены реальные строки указанного файла; объём и происхождение проверяются по манифесту.
- `SECONDARY`: найдено подтверждение только во вторичном источнике.
- `LEAD` / `CATALOG_ENTRY_ONLY`: кандидат для проверки или строка чужого каталога.
- `ASSUMPTION`: сценарное допущение команды; `SYNTHETIC` — созданные данные с описанным методом.
- `UNAVAILABLE` / `UNKNOWN`: доступ не получен или свойство не установлено. Это не ноль и не доказательство отсутствия данных.

Сильная модель также может ошибаться. При расхождении приоритет имеет проверенный первоисточник с датой и подходящей единицей измерения. Официальность источника не исправляет несовместимость показателя: агрегат аэропорта не становится спросом на отдельный маршрут.

## Границы охвата

Chrome проверен в обоих открытых профилях; Telegram прочитан в профиле mputilovskij, NotebookLM — в другом авторизованном профиле. Из чата прочитаны отрисованные сообщения релевантных тем. Изображения и видео отдельно не распознавались. NotebookLM исследован частично: список источников, существующий ответ, Deep Research, стратегия Red Wings и две таблицы. Полного экспорта блокнота не было.

Оригиналы, полные DOM, локальная расшифровка и технические сведения сессий исключены из Git. Исходная расшифровка не сверена с записью. Сообщения в группу и личные сообщения не отправлялись. Доступ к платным данным не приобретался.
