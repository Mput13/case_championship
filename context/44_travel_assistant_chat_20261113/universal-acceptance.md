# Проверка общего поиска поездки

Уточнение пользователя: примеры не ограничивают географию и не становятся отдельными правилами программы. Новая пара должна проходить тот же поиск городов/станций, аэропортов, датированных перевозок и проверку пересадок. Не добавлять ветвления по названиям демонстрационных городов. Сведения о конкретном автобусе или аэропорте допустимы как данные источника с областью действия, а не как готовый сценарий.

Ниже — задачи проверки, а не утверждения о наличии рейсов. Даты и номера перевозок назначаются только после ответа пользователя/источника. У каждого опыта фиксируются результат, покрытие, реальный источник и непроверенное.

| Задача | Что должна выявить |
| --- | --- |
| Выхино → Ханты-Мансийск | Разрешение станции внутри Москвы, выбор аэропорта, городской доезд, разумность обязательного WZ |
| Смоленск → Кисловодск | Города без аэропорта, наземный подвоз и продолжение после перелёта, несколько пересадочных узлов |
| Санкт-Петербург → Йошкар-Ола | Выбор аэропорта прибытия рядом с конечным городом; наземный участок нужен только при реальном источнике |
| Астрахань → Уфа | Обычная поездка между городами с аэропортами; отсутствие лишней мультимодальности, если найден прямой WZ |
| Новомосковск → Тула | Короткий наземный путь: требование WZ может быть неразумным, нельзя выдумывать удобный авиационный маршрут |
| Уже куплен WZ, города и номер сообщает пользователь | Рейс сохраняется, уточняется исходная/конечная точка и строится полезный подъезд вместо пересказа билета |
| Самара ↔ Екатеринбург с крайним сроком прибытия | UTC+4/UTC+5 и выбраковка физически невозможной стыковки |
| Несколько городов с одинаковым названием | Уточнение региона или станции вместо молчаливого выбора первого совпадения |
| Произвольный адрес → город без аэропорта | Геокодер/маршрутизатор или явный пробел; адрес не заменяется центром города |
| Недоступный источник и исчерпанный бюджет запроса | Не объявлять отсутствие транспорта; сохранять период и проверенные факты |

Обязательные три примера MULTIMODAL_SPEC остаются в приёмке, наряду с этими типами задач. Сценарий 2027–2028 всегда отделён от действующей сети.

Текущие ограничения реализации: одно авиаплечо, прямые наземные участки и отдельные проверенные физические переходы. Городская цепочка из нескольких перевозок, пересадочные авиационные пути и адресная маршрутизация требуют расширения коннекторов/графа. Прохождение offline-тестов не означает, что все перечисленные реальные поездки найдены.
