# Новые прямые рынки Red Wings — текущие результаты

**Начать с [итоговой записки](RESULTS.md).** В ней оба условных рейтинга, сравнение со снятием тех же доноров без замены, три конкретных оборота, условие запуска и запросы RW.

Проверены12 кандидатов; доказанно новых для RW маршрутов пока **0**. Четыре предполагаемых свободных коридора остаются UNKNOWN; на шести других есть опубликованные конкурентные nonstop, но действующий RW и его отсутствие не установлены. Две пары — очередь с низкой полнотой данных. Наблюдаемые направленные OD, сопоставимые тарифы и реальный свободный борт не подтверждены.

Начать с [обоих условных рейтингов](coordinator/rankings_both_assumptions.csv). [Пятёрка при полном P05 prior](coordinator/top5_full_prior.csv) и [пятёрка асимметричного стресса](coordinator/top5_asymmetric_stress.csv) отвечают разным допущениям о выручке. Ни один список не является готовым решением о запуске.

- [Расчёт, программы и ограничения](calculation/README.md). Включены треугольник Екатеринбург—Сочи—Минводы и обратная ориентация, отдельные челночные контроли и полная старая авторская программа с её собственным ресурсом.
- [Независимое ревью](review/README.md):16 проверок PASS, вердикт CHANGES. Две правки объяснения применены координатором в генераторе текста: асимметрия стресса и мост положительной дельты Сочи.
- [Мост доходов и расходов Сочи](coordinator/AER_result_bridge.csv). Положительное сравнение с KEEP не равно положительному самостоятельному вкладу нового рейса.
- [Receipt исправлений](coordinator/review_fix_receipt.json):18 численных артефактов побайтно сохранены, исходная панель и прежние1190 файлов не изменены. Второй независимой приёмки текста не заявлено.
- [Канонические источники новых коридоров](source_recovery_new/notes.md) и [конкурентных пар](source_recovery_competitors/notes.md); [свежие P08/P09](team_audit/README.md).

[Узкий контроль снятия доноров](cancellation_control/README.md) завершён и проверен координатором. В осторожном сценарии новые рейсы Сочи уступают снятию тех же заданий без замены. Новых пассажиров, цен, поддержки и грузов для этой проверки не добавлено. Это контрфакт модели, не рекомендация отменять действующие рейсы RW. [Воспроизведение итоговой сборки](final/verify.py).
