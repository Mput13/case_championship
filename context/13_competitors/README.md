# Конкуренты Red Wings

[Наглядный обзор](../../competitors.html): объёмы 2025, бизнес-модели, профили, сценарии конкуренции и демонстрация вместимости.

[Данные и источники](competitors.json): 10 перевозчиков/самолётных бизнесов, включая RW; 14 источников. Множитель масштаба — опубликованный годовой поток / 2.7 млн. Аэрофлот, Россия и Победа входят в одну группу; итог группы не добавлен к ним повторно. Utair — самолётный бизнес группы без вертолётов. Годовой поток не равен уникальным людям или OD.

Срез: 8 ноября 2026. Это аналитический круг конкурентов для кейса, не полный отраслевой рейтинг. Реальное пересечение линий, рыночная доля на конкретных OD, цены, себестоимость, доступный флот и прибыль не измерены. Сценарии и последствия для RW — рекомендации автора, не выявленная стратегия ответа конкурентов.

S7 теперь подтверждена текущей первичной страницей (12.8 млн за 2025); прежний контекст опирался на зеркало сообщения. Utair прочитан напрямую обычным HTTPS GET после ошибки нативного загрузчика на перенаправлении. Объём Уральских — индексированный первичный текст и вторичное подтверждение; Аэрофлот и Победа — Интерфакс по сообщениям компаний. Статусы каждого источника сохранены.

[Проверки](validation.json). Данные демонстрации 100/180 кресел условные; из загрузки не выводится прибыль.
