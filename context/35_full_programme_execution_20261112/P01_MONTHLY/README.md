# Помесячные авиационные наблюдения

Начните с `handoff.md`. Машиночитаемый вход для координатора — `handoff.json`; полный список файлов и SHA256 — `manifest.json`.

Таблицы используют UTF-8 CSV. Пустое числовое поле означает пробел. `GT`, `APPROX`, `ROUND_PUBLISHED_*` и `DERIVED_*` сохраняют границу точности. Интервалы доверия не оценивались.

`airport_monthly` и `carrier_monthly` содержат месяцы. Годовые, накопленные и летние блоки вынесены в отдельные observation-файлы. `airport_pair_segment_observations` содержит опубликованные пассажиры направлений, а `endpoint_od_observations` — только заголовок: конечные OD не подтверждены.

`calibration_eligibility` квалифицирует все 37 закреплённых известных потоков. `source_row_sha256` в нём — хеш исходной строки CSV; в новых segment observations — хеш указанной строки сохранённого текста первоисточника. `source_sha256` — хеш исходного HTTP-ответа. Эти хеши проверяют происхождение и целостность; определения и экономическую применимость задают отдельные поля и ограничения handoff.

Воспроизведение без сетевых обращений: `python3 context/35_full_programme_execution_20261112/P01_MONTHLY/rebuild.py`. Библиотеки — стандартная Python 3. Отдельный XLSX не создавался: контракт пакета требует CSV и JSON.
