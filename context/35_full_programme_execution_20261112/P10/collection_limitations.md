# Получение источников

Нативный web search использовался для обнаружения и чтения фактов; браузерные вкладки не использовались. Часть `web.open` возвращала точные ошибки `TimeoutError`, `(400) Timeout fetching` или `(502) Bad Gateway` на государственных/производственных хостах. Для известных URL продолжено разрешённое текстовое HTTP-чтение, без авторизации и без управления браузером. Это дало первичные страницы Росавиации, официальный IR-каталог и два официальных PDF Аэрофлота.

Прямые HTTP-загрузки записаны в `fetch_receipts.json`, `fetch_receipts_official_extra.json`, `fetch_receipts_method_extra.json`. Для каждого ответа сохранены дата, HTTP-статус, итоговый URL, Content-Type, размер и SHA256 тела, а при успешной загрузке — путь raw/text и SHA256 текста. Для отдельных хостов зафиксированы `HTTP 403`, `HTTP 410`, `SSLCertVerificationError: certificate verify failed: self-signed certificate in certificate chain` и `SSLEOFError: UNEXPECTED_EOF_WHILE_READING`. Проверка TLS не отключалась; доступ не объявлен успешным.

S7 прочитан через первичный текст нативного web-инструмента, прямой запрос дал 403. Методика Росстата и некоторые страницы производителей доступны только индексированным первичным текстом. Исторический сборник Росавиации скачан полностью. Текущая редакция методики 2026 года остаётся UNKNOWN. URL ОАК с параметром PAGEN при `open` дал список новостей вместо подтверждённого текста статьи; утверждение о меморандуме S7 квалифицировано как **primary indexed**, не full primary download и не факт поставок.

Собственные релизы Победы и прежний релиз Аэрофлота на АвиаПорт квалифицированы как републикации с указанным авторством. Они не названы независимыми подтверждениями тех же наблюдений. Для Аэрофлота полученный позднее официальный PDF имеет приоритет.

Никакие серверы, браузерные профили, процессы и чужие вкладки не менялись. По явному исследовательскому брифу работа выполнена самостоятельно без дочерних агентов.
