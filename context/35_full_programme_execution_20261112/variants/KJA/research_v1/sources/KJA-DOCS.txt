Алгоритм направления заявки:
1. Скачиваем и заполняем заявку.
2. Для услуг по наземному обслуживанию воздушных судов отправляем по электронной почте на e-mail: gh_ops@kja.aero;   occ@kja.aero
3. Для услуг по доставке экипажей в гостиницу отправляем по электронной почте на e-mail: dp_ops@kja.aero;    occ@kja.aero
4. Заявку направлять на указанные адреса необходимо НЕ МЕНЕЕ чем:
за 30 минут для услуг по наземному обслуживанию до предполагаемого времени выполнения работ.
за 3 часа для услуг по доставке экипажей из аэропорта в гостиницу до предполагаемого времени выполнения работ.
за 6 часов для услуг по доставке экипажей из гостиницы в аэропорт до предполагаемого времени выполнения работ.
заявка на предоставление грузоподъемного механизма направляется не позднее 15:00 местного времени (08:00 UTC) дня, предшествующего дню предполагаемого выполнения работ.
