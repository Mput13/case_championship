## Формула и единицы

`n_out*r_out + n_back*r_back − actual_lost_RW_contribution − additional_variable_pax_cost − launch/overnight/reserve/other F > cost_roundtrip + actual_displaced_other_job_contribution`.

Равенство даёт нулевой вклад; строгая прибыль требует floor+1 билета. `L = k_out*oldnet_out + k_back*oldnet_back − recapture − saved_old_pax_variable`. k — перешедшие из прежних продуктов RW, а не весь новый рейс. Доп.pax — только неучтённые расходы нового рейса. Нельзя после L повторно вычитать общий joint loss. `--lost-rw-contribution-rub` альтернативен k/share. Все рубли номинальные, без выдуманного НДС. Входы L/recapture/saved/D/recurrent F заданы на оборот; oneoff F — один раз на выбранный горизонт.

Для месяца: `4*[n_out*r_out+n_back*r_back−L−pax−recurrent F−D−C_RT]−F_once`. Один оборот — 2 рейса; февраль — 4 оборота, 8 рейсов, максимум 400 билетов/направление, 800 всего. Один RT-клиент покупает 2 one-way билета; количества здесь не уникальные люди. Тариф не умножается на4 повторно. FEB4_REPEAT требует одинаковые целые продажи на каждом повторе; FEB4_POOLED разрешает различия между неделями и проверяет месяц целиком, а не прибыль каждого оборота.

В коде `a_out=r_out−pax_variable_out−s*oldnet_out`, аналогично `a_back`; s используется только в пропорциональном стрессе. `L0=k_out*oldnet_out+k_back*oldnet_back−recapture−saved` — фиксированный вычет; при s>0 фиксированные k запрещены, и переток учитывается только в a. Альтернативный уже известный L вводится вместо k/s. Полная формула `qback_min(qout)=max(0,floor((C_RT+L0+F+D−qout*a_out)/a_back)+1)`, с дополнительным ограничением не меньше числа перешедших билетов. Каждое плечо отдельно ≤100. directional_frontier.csv содержит также оба месячных критерия. Самоокупаемость каждого плеча — отдельная необязательная диагностика: оборот допускает перекрёстное покрытие, F/D не приписаны произвольно одному плечу.
