# Границы делегирования

Первый проход выполнен параллельно, без дублирования областей:

| Модель | Задача | Результат |
|---|---|---|
| GPT-6-luna | Оренбург: пересадка, SSJ, поток2025 | CSV/заметки; новые первичные факты не подтверждены |
| GPT-6-luna | Самара: пересадка, SSJ, статусRW | Завершено без файлов/проверки первоисточников; входы не приняты |
| GPT-6-luna | Омск: базы перевозчиков, SSJ | Найдена первичная публикация ТО; ошибочный знак влияния и категорическое отрицание базы отклонены координатором |
| GPT-6.1-sol | Методика, веса,500км и Самара | Спецификация весов и правил |
| GPT-6.1-sol | Python и соответствие панели | Baseline, ошибки, исправления, runner |
| GPT-6-astra | Независимая проверка существенных выводов | Шесть замечанийR1–R6 |

Единственный адресный раунд состоял из зависимых частей: Luna завершила узкую проверку двух пробелов (новых подтверждений не получила); координатор проверил уже названные первичные страницы; Sol интегрировал явно принятые факты/методику; Astra выполнила независимую приёмку. Третий раунд и общий повторный поиск не запускались. Итог: ACCEPT_WITH_LIMITATIONS, остаточные дефекты раскрыты.

Модели были доступны, замен не было. Агенты не меняли ветку и не публиковали результаты. Коммиты и публикация — только координатором в отдельную ветку; служебные идентификаторы заданий оставлены локально.
