Два случая учёта:

1. **Новая аренда для проекта.** Incremental cash — реально возникающие платежи по новому договору за подтверждённые месяцы, плюс отдельные договорные endorsements страховщика. Аванс, refundable deposit, выкуп и capital value не годовая аренда. Full-PnL отражает классификацию договора: для finance lease нельзя складывать весь cash payment с амортизацией и процентами. Maintenance reserves показываются отдельно с overlap gate.
2. **Уже оплачиваемый действующий борт.** Full-PnL allocation аренды/страхования существует. Дополнительный cash может быть0 ТОЛЬКО если подтверждены уже оплаченный график, отсутствие нового tail/продления/повышения премии и одинаковые обязательства во всех сравниваемых сценариях. UNKNOWN не превращается в0. Если борт снят с донорских рейсов, упущенный вклад D остаётся отдельной opportunity cost; не вычитать его повторно после joint delta. Фиксированная аренда не является избегаемым расходом отменённого flight; страховая экономия также требует endorsement/return-premium clause.
