# P38 — совместная экономика полного месяца

Прямой проектный вариант для обсуждения, **не принятая корпоративная стратегия**. Завершённый вход programmes/ принят по явному completed gate. Расчёт охватывает 436 календарных вариантов / 420 финансовых классов, все 60 прежних P36, 12 полных месяцев 2027 и BASE/CAUT. Все 25 seed-пар сохранены, включая платные CEK–SVX и SVX–TJM без продажи кресел. Дополнительные плечи завершённых шаблонов показаны отдельно от seed и от рыночного admission.

Ни один найденный сценарный subtotal не является actual profit/cash. Actual endpoint OD, net settlement, свободный парк, полный RW invoice, C/D/F/R1 и операционный допуск не установлены. Qualified fare updates0, OD updates0, invoice replacements0. По данным MAIN не обоснован запуск восьми новых маршрутов. Слабые плечи для выполнения количества не добавляются; true own newness остаётся UNPROVED. Старый top5 и AER frequency controls сохранены как проверки, а не как доказанная новая пятёрка.

В интегрированном основном расчёте CAUT все 5 232 новых programme-month R−W отрицательны. Положительный R−K в части случаев объясняется изменением старой работы и не является аргументом запуска новой цепи. BASE даёт условно положительные вклады, требующие проверки net/OD, цены альтернативы и всех неучтённых потерь. Нельзя рекомендовать пилот из-за меньшего убытка.

Экономика MAIN — DIRECT_ONLY. Один направленный city OD/month, DME/ZIA — разные физические аэропорты внутри одного MOW pool. Все old/new кресла считаются совместно. P05 annual prior переводится в potential travel через .6 один раз; месячная доля — действующий исторический Aeroflot Group2025 carrier profile, не RW route forecast. CAUT annual .962 применяется один раз. MAIN направления 50/50, месячно гибкие даты без выдуманной надбавки к цене. Тариф за journey один; ferry0 seats/q/revenue, но полный расход сохранён.

Late P01/P09 historical carrier/airport **segments** не приняты за endpoint OD или полный рынок. Наблюдавшийся KJA–SVX carrier segment не задаёт bound конечных поездок2027. Q1/FY не превращаются в март/декабрь, H1 не удваивается, group и carrier subset не суммируются. Lineage и ограничения сохранены в completed `monthly_input_audit.csv` и input manifest.

Ускорение точное в рамках direct-only: физически одинаковые по airport/block/price legs симметричны. Для каждого OD решается `potential = outside_mass×λ + Σ min(seats_i, weight_i×λ)`. Это та же simultaneous recapture аллокация P06; каждый leg получает свою долю и не превышает100. Эквивалентность проверяется полным P31/P06, включая mixed K1/K2/K3, MOW и price rechoice. Through эту факторизацию не использует: отдельный полный P06 rerun, endpoint fare один раз и оба leg seats один раз. Неподтверждённый through не включён в MAIN.

`pair_month_thresholds.csv` содержит две разные проверки. `same_K_W_*` — сколько нужно одной указанной паре/дирекции, чтобы вся закрытая цепь оправдала себя против KEEP и того же изменения без новой работы. Основные `required_*` — против всей заявленной feasible same-cohort menu. В обоих случаях меняется **только один directed pool**, остальные фиксированы, включая альтернативы. Piecewise capacity intervals дают точный численный inverse внутри этого конечного меню. `NO_OD_WIN_ANY_POTENTIAL_WITHIN_THIS_MENU` означает отсутствие победы даже при насыщении кресел при фиксированных остальных ценах/рынках; это не утверждение об универсальной непригодности рынка. Строго равная альтернатива не считается выигрышем. Net inverse меняет реализованный net всего указанного city-direction при фиксированном retail gross/choice; это settlement threshold. Изменение retail fare отдельно пересчитывает choice. Новый внешний own loss потребляет общий headroom и не равен фактическому нулю.

Стоимость — подписанный RRJ/SaM146 сценарий P36, не PD8 и не новый invoice. Fuel tonnes×landed ₽/t один раз; BASE136300+1696, CAUT161696. Fixed crew15/22тыс/BH исключён один раз; fixed lease/payroll не экономятся. Public SVX component rates не прибавлены к ground. MAIN deice15/40тыс — **консервативный all-year allowance**, не факт обработки в августе. Incidence0/25/100% показана отдельно. Все238 прежних CAUT directed full100 ceilings остаются отрицательными даже при incidence0; это standalone direct bound, не through/global proof.

Primary K1 — точные 11 T1 old jobs; K2 —15 B2; K3 —те же15 плюс условный T3 с D3 UNKNOWN. R1 единственный отдельный, не рабочий. K2−K1 никогда не называется ценностью борта. Secondary frontier решён на одном master15: route-family subsets, старые и mixed source programmes с assignment целых closed jobs; shadow K1 снимает4 T2 obligations с явным C UNKNOWN. При добавлении бюджета lower allocation сохраняется с idle extra tail, включая все K2 альтернативы в K3. Значения точны только для заявленного menu/policy set; global gap UNKNOWN. `V(k+1)−V(k)` до differential C/D/lease/R1/setup — условный потолок дополнительных платежей, не прибыль и не доказанный global optimum. Internal own shift и потеря моделируемых старых продуктов уже вошли в joint delta; второй раз их не вычитать.

Full jobs на месячном переходе не режутся: выбор по месяцу первого вылета job, стоимость полного flight по UTC departure month, BH разбиты в полночь, readiness/position не reset. При seasonal conflict независимая сумма остаётся upper bound, присутствует feasible fixed fallback. В resource frontier годовые lower/fixed/monthly policies отдельно stitched с наследованием нижнего решения. Entry cases проверяют даты новых ресурсов; конфликтующий entry-policy заменяется проверенной base1 policy с idle дополнительными хвостами, а optimistic envelope остаётся отдельным. Actual annual entry/return state вне выбранных операций UNKNOWN. Seasonal setup/станционные минимумы не объявлены бесплатными.

Пилоты — проекты расчёта, не рекомендации. KJA/IKT исходно1RT/week; GOJ–KJA берёт минимальную completed mixed программу с обеими коммерческими дирекциями, её фактическая сценарная частота напечатана. Четыре недели —01–28.02.2027. BASE/CAUT и пять явных stress worlds пересчитывают также альтернативы. Integer ticket limits требуют строгого `>0`; границы против KEEP/same-W отделены от цены выбора всей программы против лучшей иной программы. Full100 других плеч — лишь capacity boundary. Funding gap — условная opportunity/accrual разница до неизвестных differential C/D/F; неизвестный C альтернативы может поменять ranking. Полный cash budget задан формулой по cumulative paid cash, одобренный риск и дедлайн бесплатной отмены NULL. Expansion только при положительном добавочном joint результате после всех потерь и наблюдаемых подтверждений.

Поставку нельзя подменить entry; до entry рейсов нового борта нет. 2028 OD/cost/calendar не экстраполированы из 2027.
