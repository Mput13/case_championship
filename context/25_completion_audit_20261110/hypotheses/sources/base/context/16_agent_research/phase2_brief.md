## Ожидаемый результат

Подготовить первый воспроизводимый проход по конкретным пассажирским продуктам и вариантам сети: источники → совместимые таблицы → датированный продукт → условия выполнимости → условные денежные пороги → независимая проверка. Конечный спрос, получаемая выручка и реально доступный парк остаются UNKNOWN, если новые источники их не измеряют. Не создавать ещё одну красивую объяснялку вместо этого прохода.

Три основных опыта: C14 Киров–Минводы с санаторной поездкой; C01 новая волна в Уфе против тех же рейсов без координации; C07 цепочка SVX–OMS–KJA против сопоставимого использования существующего ресурса. Это исследовательская очередь, не рекомендованная сеть. Этап20 коллег добавляет полезный отдельный контрфакт замены действующего оборота: донора нельзя выдумывать по плохой сценарной экономике дополнительного рейса.

## Гипотезы и расчёт — Astra

Начать `experiment_v1` для трёх опытов на одном неизменяемом контракте. Сначала зафиксировать входы, baseline и список необходимых таблиц. Известные наблюдения не заменять выдуманной калибровкой. Сценарный числовой пример разрешён только с явным происхождением параметров и отличием от результата на реальных данных. У хаба сравнить одинаковые ноги с синхронизацией и без; не давать ему бесплатный парк/базу. У цепочки учитывать все плечи и позицию борта. У замены действующего рейса сохранять донора UNKNOWN и показать, какие сведения нужны для честного сравнения сохранить/заменить/убрать. Хранить все попытки и причины отказа. Итог может быть интервалом или порогом смены решения; не требовать победителя при недостаточных данных. Первые результаты передать критику до конца двухчасового окна.
