Прочитать точные условия context/00_brief/case5_requirements.md и https://mai-way.ru/tasks/red-wings/ прежде чем трактовать требования. OBSERVED / DERIVED / MODEL_ESTIMATE / SCENARIO / UNKNOWN различаются. Пропуск не ноль. Сбор из нескольких реальных источников не делает данные синтетическими; оценка неизвестного OD — модельная оценка. Сценарий не доверительный интервал.

Основной предмет: конкретный пассажир/цель/пара/сезон, почему текущие варианты неудобны, почему выберет RW, откуда прирост (чужой поток, поезд/авто, индуцированный, собственная каннибализация), конкурент и ответ, спрос/нетто-тариф/частота/операционный ресурс, risk/reward, как проверить и при каком результате отказаться.
