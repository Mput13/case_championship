# Карта гипотез направлений для Цикла 2 (1 лист к встрече 26–27.11)

**Назначение:** рабочий список из 12 межрегиональных и контрольных направлений для согласования приоритетов Цикла 2 с Red Wings (включая три примера из постановки брифа: `Волгоград ↔ Омск`, `Омск ↔ Красноярск`, `Омск ↔ Томск` и один железнодорожный контрольный кейс).  
**Важно:** в этой таблице намеренно **нет непроверенных модельных чисел спроса (`[MODEL]`)** — объёмы и диапазоны `Min/Base/Max` рассчитываются в Фазах 1–2 Цикла 2 только по коридорам с локальным физическим якорем и проверкой на контрпример.

*Примечания по дистанции:* для 5 пар, уже входящих в [fleet_and_distance_matrix.csv](../51_corporate_expert_kit_20261124/fleet_and_distance_matrix.csv) (`LED–SVX`, `UFA–NUX`, `IKT–PEE`, `IKT–MJZ`, `SVO–ULY`), приведены точные значения матрицы; для 7 новых пар ортодромия и `×1,10` рассчитаны по WGS-84 координатам аэропортов. Ориентир `2 355 км` ортодромии — предварительный отсев `SSJ-95B` (окончательная выполнимость требует лётного расчёта RW). ### Как используем карту на встрече и в Цикле 2
1. **На встрече 26–27.11:** уточняем у Red Wings, по каким из 12 пар уже были отклонённые групповые заявки, какие пары попадают в действующие отборы субсидий 2027 г. (включая `IKT–PEE`) и по каким направлениям можно запросить обезличенные агрегаты через авиахолдинг Ростеха.
2. **В Фазе 1 Цикла 2 (30–35% ресурса команды):** проверяем по всем 12–15 коридорам недельный профиль расписаний (Пн–Вс, деловое ядро Вт–Чт), фактические табло и встречные контрпримеры; выносим `Working No-Go` там, где гипотезу опровергает первичный факт (как релокация вместо вахты у СИБУРа).
