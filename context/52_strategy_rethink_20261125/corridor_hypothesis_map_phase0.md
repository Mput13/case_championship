# Карта гипотез направлений для Цикла 2 (1 лист к встрече 26–27.11)

**Назначение:** рабочий список из 12 межрегиональных и контрольных направлений для согласования приоритетов второго этапа исследования (Цикл 2) с Red Wings, включая три примера из постановки брифа (`Волгоград ↔ Омск`, `Омск ↔ Красноярск`, `Омск ↔ Томск`) и один железнодорожный контрольный кейс.  
**Важно:** в таблице **нет модельных оценок спроса и финансового эффекта** — решение о запуске рейсов по этой карте принимать нельзя. Количественные диапазоны строятся в Цикле 2 только для коридоров с локальным физическим якорем и проверкой на контрпример.

*Технические примечания:*
- **Координаты и округление:** для 5 пар, уже входящих в [fleet_and_distance_matrix.csv](../51_corporate_expert_kit_20261124/fleet_and_distance_matrix.csv) (`LED–SVX`, `UFA–NUX`, `IKT–PEE`, `IKT–MJZ`, `SVO–ULV`), взяты точные значения матрицы; для 7 новых пар ортодромия и маршрут `×1,10` рассчитаны по КТА/координатам WGS-84 (АИП / OurAirports) с округлением до целых километров (расхождение 1–2 км между источниками координат не меняет предварительный отсев).
- **Отсев по дальности:** ориентир **`2 355 км` ортодромии** (при коэффициенте маршрута `×1,10`) — консервативный предварительный отсев для **базового `SSJ-95B`**, а не окончательный запрет для всего семейства ВС; фактическая выполнимость подтверждается лётным расчётом Red Wings.
- **Субсидии:** коммерческая база всегда считается при `0 ₽` субсидий (ПП РФ № 1242 отменено п. 12 ПП РФ № 707 с 31.05.2025; ПП РФ № 245 — п. 33 ПП РФ № 1665 с 09.11.2025). Действующие отборы 2027 г. учитываются отдельным слоем после проверки финансирования и совместимости с блоком.

### Как используем карту на встрече и в Цикле 2
1. **На встрече 26–27.11:** уточняем у Red Wings, по каким из 12 пар были отклонённые групповые заявки, какие пары попадают в действующие отборы субсидий 2027 г. (включая `IKT–PEE`) и по каким направлениям можно запросить обезличенные агрегаты через авиахолдинг Ростеха.
2. **В Цикле 2 (30–35% ресурса команды):** проверяем по всем 12–15 коридорам недельный профиль расписаний (Пн–Вс, деловое ядро Вт–Чт), фактические табло и встречные контрпримеры; снимаем с проработки направления и когорты, где гипотезу опровергает первичный факт (как релокация вместо вахты у СИБУРа).
