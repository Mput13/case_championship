# Дополнительное исследование Terra

Срез — **7 ноября 2026**. Дополнение к уже собранным данным, методам и конкурентам: похожие исследования, инструменты проверки расписаний и новые практические аналоги. Материалы подготовлены GPT‑6.1 Terra xhigh для оценки релевантности; сеть Red Wings, спрос и экономический результат здесь не рассчитаны.

Начать с [обзора восьми кандидатов](report.md): что каждый добавляет к прежним материалам, какой результат можно получить и что ограничивает применение.

| Направление | Отчёт | Источники |
|---|---|---|
| Похожие работы: синхронизация, внешняя альтернатива, устойчивость сети | [Исследования](terra_similar_studies/report.md) | [10 карточек](terra_similar_studies/sources.csv) |
| Инструменты: обороты самолётов, стыковки и граф событий | [Инструменты](terra_practical_tools/report.md) | [10 карточек](terra_practical_tools/sources.csv) |
| Практические аналоги: Avelo, airBaltic, Nordica; условия программы Augusta | [Аналоги](terra_network_cases/report.md) | [7 карточек](terra_network_cases/sources.csv) |

В трёх CSV — **27 карточек и 27 различных URL**, без точных совпадений с каталогом до добавления пакета. Источники включены в [общий реестр](../05_datasets/README.md); подробности чтения, даты и ограничения сохранены в исходных CSV.

`VERIFIED_PRIMARY` означает прочитанное содержание первичного документа в указанном объёме: 25 карточек имеют этот статус, одна — `SECONDARY`, одна — `LEAD`. Самоотчёт компании не является независимой оценкой её результата. Предложения по применению — `ASSUMPTION`; эксперименты на реальной сети не выполнены. При выборочной повторной проверке синтеза PDF Seredyński вернул ошибку сервера — это отмечено в [обзоре](report.md).

Дополнение развивает [проверенные методы](../07_verification/terra_methods_data_review/usable_methods.md) и [вопросы, меняющие выбор сети](../06_ideas/decision_questions.md), не заменяя их. Для источников сохраняется различие между чтением документа, доступом к данным и подтверждением применимости к Red Wings.
