# Исследовательские черновики Flash

Эти материалы созданы Gemini 3.8 Flash Medium для широкого поиска. Пометки `VERIFIED_SOURCE` внутри них отражают заявления исследователя, а не окончательный статус общей базы.

Уже обнаружены повторные неподтверждённые тезисы о фиксированном парке, универсальных параметрах хаба и эксплуатационных нормах. Многие ссылки ведут на главную страницу вместо конкретного документа. Сами тексты сохранены для аудита и повторной проверки; готовыми исходными данными для рейтинга они не являются.

Проверка городов и конкурентов, методов и внешних данных выполнена независимо GPT‑6.1 Terra xhigh. Итоговые исправления находятся в `../07_verification/`. До проверки спорное число остаётся неизвестным или сценарием.

| Папка | Назначение |
|---|---|
| `flash_aviation_data` | Источники авиационных данных и расписаний |
| `flash_cities_competitors` | Лонглист 20 городов и контекст конкурентов |
| `flash_methods` | Методы, библиография, 14 идей для проверки |
| `flash_external_data` | Демография, туризм, экономика, наземные альтернативы, погода |

Файлы в `samples` могут содержать реальные выгрузки, преобразования и примеры схем. Название папки само по себе не доказывает происхождение строк. Проверенные образцы Terra с описанием происхождения и SHA-256 находятся отдельно в `../07_verification/terra_data/samples/`.
