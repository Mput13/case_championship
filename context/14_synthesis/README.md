Названия «Настя» и «Цири» не сопоставлены с Git-логинами без доказательства. Формулировки «решения команды» из конкретной ветки сохранены как её документированные установки, а не автоматически принятые общие правила. Пакет не назначает ответственных и не отправляет сообщения коллегам или компаниям.

[Закреплённые входы](inputs/manifest.json) содержат точные копии выбранных таблиц и JSON, SHA256, commit и происхождение примеров. Эти файлы остаются сценарными там, где сценарными были их входы. Основной вывод — пока нет доказанного проекта запуска; относительное преимущество одной отрицательной схемы не является прибыльностью.
