# Как повторить P38

Основные данные и итоговые таблицы уже сохранены. Команды выполнять из корня репозитория с Python 3. Файлы исходной модели/панели и предыдущих исследований не перезаписываются. Git, сеть и бронирования расчётный код не вызывает.

```bash
# Основная экономика, затем точный экспорт частот всех месяцев.
python3 -B context/38_direct_strategy_20261113/economics/calculate.py
python3 -B context/38_direct_strategy_20261113/economics/finalist_months.py
python3 -B context/38_direct_strategy_20261113/economics/verify.py

# Завершённый отдельный стресс задержек 60/90 минут обслуживания.
python3 -B context/38_direct_strategy_20261113/economics/delay_stress.py
python3 -B context/38_direct_strategy_20261113/economics/delay_stress.py --verify

# Сборка только представления, затем итоговые read-only проверки.
python3 -B context/38_direct_strategy_20261113/final/build_report.py
python3 -B context/38_direct_strategy_20261113/final/verify_final.py
```

Для быстрого контроля готового пакета достаточно двух последних `--verify`/`verify_final.py` команд; полный многомесячный перебор повторять для чтения отчёта не требуется. Если в системе нет зависимостей старого P06, в исходной исследовательской копии расчёт также исполнялся через `context/28_end_to_end_audit_20261110/code/sandbox/venv/bin/python`. Этот локальный venv не является переносимым артефактом Git. Зависимости и входы движка описаны в [contract](../contract/README.md), [programmes](../programmes/README.md), [economics](../economics/README.md). Реконструкция публичных источников офлайн использует сохранённые выдержки/PDF/HTML, а не повторное открытие изменяющейся страницы.

## Модели и формулы

- **Спрос/выбор:** унаследованный P05/P06 сценарный potential по направленному city OD/month и совместное распределение между RW и внешней альтернативой. Для direct-only используется точная факторизация ограниченного креслами распределения: `potential = outside_mass × λ + Σ min(seats_i, weight_i × λ)`. Проверена эквивалентность полному P06 на выбранных случаях, включая общую московскую OD-пулу. Это модель, не измеренный OD или доказанные дополнительные пассажиры.
- **Сезонность:** перенос исторического месячного профиля внутренних перевозок группы «Аэрофлот» за 2025 год; направление 50/50 — допущение. Пиковый стресс перераспределяет тот же месячный объём по датам. Ежемесячные значения не объявлены прогнозом RW.
- **Экономика:** net один раз на journey; платный ferry без пассажирской выручки; fuel tonnes × ₽/т, uplift один раз. Оклад/аренда не объявляются избегаемой экономией. W/R используют одинаковые изменения старых заданий; `R−K = (W−K)+(R−W)`. Неизвестные C/D/F/R1/внешний переток вынесены в пороги. Через-пассажир в отдельном through-сценарии занимает оба плеча, тариф оплачивает один раз. В MAIN through/support/cargo/block не добавлены.
- **Сети:** конечный перебор замкнутых заданий, ограниченный beam и совместное месячное распределение. Это не доказанный глобальный optimum/MILP и не простая сумма прибыли пар. Все границы/обрезания — [search coverage](../programmes/search_coverage.json) и [economics coverage](../economics/search_coverage.json).
- **Календарь:** непрерывные позиция и готовность хвоста, UTC/local, завершение whole-job, отдельный резерв, годовые швы. 8 BH — диагностический порог, не норматив FDP. Для задержки `dep_actual = max(dep_plan, previous_arrival_actual + turn, shocked_baseline_departure + hold)`; последний аргумент действует только на выбранный trigger. Zero-shock baseline при том же turn считается отдельно.
- **Обратные задачи:** целочисленный билетный порог при фиксированном net; направленный OD inverse при фиксированных остальных рынках; settlement/net threshold при фиксированном retail choice. Изменение публичной цены пересчитывает выбор отдельно. Эти тесты отвечают на разные вопросы и не суммируются как независимые источники спроса.

## Что независимо проверено

Оригинальные [review/README.md](../review/README.md), код и actual-run log сохраняют вердикт **CHANGES**: 12 групп проверки прошли в своей области, но отсутствовал delay-turn90. Координатор исправил этот локальный пробел отдельным модулем и проверил его скалярной рекурсией; это не выдаётся за повторную независимую приёмку. Исторические turn60-only файлы не удалены. Финансовая приёмка не равна подтверждению рыночных предпосылок. Полный фактический PnL/cash/dispatch остаётся неизвестным.

## Известное использование ИИ

В данном P38 задания исследования рынков/расходов выполнялись делегированными агентами **GPT-6-luna**. Их неполные результаты не принимались как готовые численные обновления. Адресный допуск, контракт, недельный генератор и экономика — **GPT-6.1-sol**; независимая методическая/численная проверка — **GPT-6-astra**. Координатор выполнил ограниченное исправление turn90 и сборку итогового представления. Доказательства состава заданий: файлы `*task.local.json`, `delegation.local.json`, `addressed_round.local.json` в корне P38 и actual receipts внутри пакетов. Данные не получали статус факта только из-за ответа модели или PASS схемы CSV.

Модели/промпты, использованные авторами общей панели и всех прежних командных материалов, этим пакетом заново не установлены. Пробел не заполняется догадками.
