# P38 SVX market evidence

## Решающие находки

1. Первичный архив Кольцово доступен по `ar-svx.ru/schedule/` и `?type=arr`; времена локальные. Ошибка `svx.aero` в раннем поиске не означает отсутствия первичных данных.
2. Для KJA P37 подтверждает опубликованные рейсы «России»: 7 направлений в неделю в неделе 16–22 ноября; на 1–7 февраля видны только вторник/суббота. Горизонт неполон, поэтому неизвестные дни не объявляются отсутствием. RW own nonstop этим не опровергнут.
3. MRV имеет только опубликованный аналог 2026 из P34 в текущем пакете; он не продлён на 2027. Для остальных пар отсутствие извлечённой строки не трактуется как отсутствие рейса.
4. Тарифные правила RW: Standard включает 20 кг, Light — платный багаж; сопоставимых датированных итоговых цен по парам нет. Цена UNKNOWN, численно не принимается.
5. Для CEK/TJM/TOF коммерческий passenger demand не установлен; позиционирование/ferry остаётся возможным. Для CEK/SVX нельзя изобретать спрос.

Покрытие: все 9 назначенных SVX-пар; другие 16 пар вне scope. Опубликованный supply не равен OD demand. Own RW connecting — возможный переток, не новый рынок. Не выполнялся исчерпывающий отдельный поиск цен/альтернатив на все даты; пробелы отмечены. Летняя проекция не используется как доказательство продаж.
