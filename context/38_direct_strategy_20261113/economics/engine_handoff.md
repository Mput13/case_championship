# Handoff координатору — P38 economics

Рабочий движок: `core.py` + `calculate.py`, конфигурация `config.json`; затем `finalist_months.py` дополняет receipt точными месячными частотами. Приняты только завершённые contract/market_admission/cost_admission и явно переданный completed programmes gate. Прочитаны schema `P38_WEEKLY_PROGRAMMES_1`,420 финансовых классов/436 вариантов, nested8. Старые60 восстановлены exact API completed adapter и сверены с legacy map нового пакета. Субагентов, внешнего поиска, контактов, Git/commit/push/panel не было; запись ограничена economics/.

Не принимать проверку структуры за actual market/dispatch acceptance. Полные фактические деньги, actual OD/net, C/D/F, доступность рабочего парка/R1 и операционные разрешения всё ещё NULL. Не менять города/паспорт команды на основании этого пакета. Результат — конечный условный programme search с раскрытым global gap, не корпоративная стратегия и не глобальный оптимум.

Порядок приёмки:

1. `validation.json`, `run_receipt.json`, `repeatability.json`: фактическое исполнение, hashes всех данных, независимые P06 equivalence checks и два полных deterministic финансовых запуска. Дополнительно `finalist_months_validation.json`:36 exact month calendars и432 строки месячных частот; этот генератор также дважды исполнен в свежих процессах с одинаковыми bytes. Composite receipt объединяет25 финансовых и2 дополнительных артефакта; это явно два компонента исполнения. Guard содержит registry1621,1614 immutable и7 исключённых mutable orchestration metadata. Старые файлы не изменены.
2. `programmes_monthly.csv`:436×12×2×3 +216 primary KEEP-control rows. K1 содержит11 old jobs T1; K2/K3 —15. R−W, W−K и R−K всегда отдельны. Нельзя выдавать преимущество removal за доход новой цепи.
3. `pair_results.csv` и `pair_month_thresholds.csv`: seed25 полностью, дополнительные source-template pairs явно помечены. Отсутствующее коммерческое направление и positioning имеют конкретный reason. Own RW publication periods приложены; expired Dec не становятся supply на февраль/лето. Нет numeric price admission. Все коммерческие направления имеют dated monthly frequency и inverse либо явную unsupported/no-crossing границу.
4. `annual_results.csv`, `season_vs_yearround.csv`, `seasonal_plan.csv`: сравнение fixed weekly с monthly choice на одном парке/мире. Первая departure job определяет policy; crossing flights целиком завершаются. Ресурсные/календарные конфликты нельзя замаскировать суммой monthly optima. Физический year-wrap — условная periodic fixture, не actual outside return-state.
5. `resource_marginal.csv`: фильтры `FINITE_MENU_FRONTIER`, `ANNUAL_STITCHED_FINITE_FRONTIER`, `PROVIDED_EXACT_NESTED_PAIR`. Во всех master15; primary K1 не подменён shadow allocation. У shadow1 четыре исходных T2 obligations сняты с C UNKNOWN. Lower allocations встроены в следующий бюджет с idle tail. Все8 supplied K2→K3 pairs пересчитаны совместно на12 месяцах×2. C разных menus пока не известен; actual incremental profit NULL. `opportunity_curve.svg` вычитает общий extra burden из годовых stitched paired ceilings, а не raw primary K2−K1.
6. `delivery_cases.csv`: RRJ-equivalent envelope отдельно от date-entry checked/fallback policy. Численный SJ variable/BH ceiling не является RRJ→PD8 cost admission. Actual SJ margin NULL; S1D6 не создаёт доход2027. При entry seam conflict используется проверенный lower/base1 idle-extra-tail fallback, а не бесплатный reset.
7. Три distinct K2 weekly programme finalists: ranking по годовому известному R subtotal при положительном R−W BASE, разные closed-path recipes, до неизвестных C/D/F. Они показывают полезные programme choices, а не доказанные новые рынки. Для них four-season weekly calendars, `three_finalists_monthly.csv` со всеми12 месяцами/плечами/хвостами/old-new/ferry, dated representative ledgers, turn60/90, hold30/60/120 retained/new. Триггеры охватывают сезонную ISO-неделю, последние2 дня месяца и30–31 декабря; readiness продолжается через месяц/год. Latest-slot/FDP/RUB cancellation cutoffs не придуманы.
8. `pilots.csv`:2×5 stress worlds для каждого из3 проектов,4 недели. KJA/IKT1RT/week; GOJ–KJA обе ориентации из минимального доступного completed programme. Все alternative states пересчитаны в том же stress world. Integer/цена/F/funding границы не являются авторизацией бюджета. Без положительного дополнительного результата или явно оплаченного полезного эксперимента запуска не рекомендовано.

Главный содержательный вывод MAIN: CAUT не допускает новую цепь по положительному R−W ни в одном из436×12 вариантов; часть R−K положительна из-за old changes. BASE — условный screening. Требование8–12 маршрутов не закрыто доказательствами прибыльных новых markets: очередь существует только с адресными OD/net/F/resource/ops conditions. Current own/connecting потери за пределами fixture не нулевые факты, а обязательные неизвестные вычеты из одного headroom.

Адресная независимая проверка: возьмите один old+один mixed вариант из каждого primary cohort, восстановите KEEP/action_map/W/option_ids/R, проверьте полную календарную непрерывность и сравните full P06 с kernel; затем один directed OD inverse с фиксированными остальными рынками; master15 lower/upper identity; whole-job transition; dated entry. `verify.py` делает эти проверки сам, не вызывая прежние verify/build/export. Структурный PASS не снимает actual gates.

Продолжение без research: подставить подтверждённые route-month OD и settlement net через explicit overrides, полные новые unit costs после overlap/tax bridge, exact availability/FDP/slots и C/D/F/R1. Пересчитать одно и то же меню/мир/ресурсы. Для net-only изменения сохраняется gross/choice; для retail gross изменения обязательно rechoice. Закрыть station minima/payment/exit dates до расчёта cash budget. Для PD8 дать отдельную типовую cost function — прежняя намеренно отвергает SJ.

Неисследованное пространство: другие clocks/частоты/совмещения вне generator beam; полный own connecting/interline/3+leg inventory; cross-month through sales; фактический dispatch; actual demand calibration;2028 economics. Through/support/block/cargo — отдельные conditional scenarios; main incremental support/block/cargo0. Новых внешних фактов после completed inputs не добывалось.
