# Прямые рейсы: результат для команды

**Первым проверить Екатеринбург — Красноярск; запуск пока не обоснован.** В BASE проверенный один оборот в неделю окупает учтённые переменные расходы примерно при 69 билетах в каждую сторону и сценарном net 14 437,70 ₽. В CAUT нужно 115 при 100 местах. Доходность реального борта, внешнего перетока и всех расходов ещё неизвестна.

Сочи — сильнейший BASE конкурент за ресурс в проверенном общем меню; его нельзя исключать из сравнения новых пар. В осторожном расчёте все 5 232 сочетания «программа × месяц» новых цепочек проигрывают тем же изменениям без новых рейсов. Не рекомендуем пилот только ради меньшего убытка; текущие обязательства сохраняем до проверки альтернатив и стоимости их снятия.

На действующем освобождаемом парке — условные 1/2/3 рабочих+отдельный R1. Вложенное BASE сравнение даёт потолок 1→2 до 89,210 млн₽/год до дополнительных потерь/платежей;2→3 даёт 0 в этом меню. SJ учтён только после H2 2027 и сценарного entry; фактическая экономика PD-8 и 2028 не установлена.

**Три действия:** получить направленные продажи/net и собственные рейсы RW; подтвердить хвост+резерв/оборот/экипаж/слоты; получить invoice и вклад вытесняемой работы вместе со стоимостью отмен/запуска. Ни рейтинг, ни сценарная прибыль не заменяют эти данные. Панель, паспорт и выбранный командой город хаба не менялись.
