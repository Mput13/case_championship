# case_championship — кейс Red Wings

Кейс-чемпионат МАИ «Связанность территорий», кейс Red Wings: «Новый хаб или прямые рейсы?»

## Итоговая панель

[Интерфейс](outputs/redwings_panel.html), [книга расчётов](outputs/redwings_model.xlsx), [паспорт 10 ноября](docs/29_passport.md). Паспорт отражает предыдущий расчёт и требует сверки с текущей моделью перед защитой.

Повторная сборка из сохранённых входных данных без загрузки новых источников:

```powershell
py -3.13 scripts/build_release.py
```

Нужны pandas, numpy, openpyxl, matplotlib, pytest и xlrd (читает файл статистики «Аэрофлота»), а также сохранённые исходные и промежуточные таблицы проекта. Скрипт останавливается при ошибке. Проверка готовой сборки: `py -3.13 scripts/check_release.py`. Проверка интерфейса в установленном Chrome: `py -3.13 tests/check_panel_browser.py` (требуется Playwright).

Эта команда использует сохранённые таблицы спроса: после правки `known_flows.csv`, данных населения или параметров модели спроса сначала нужно пересчитать зависимые шаги (`demand_model.py`, `demand_summary.py`, `od_model.py`, `demand_compare.py`; при изменении населения также подготовить `catchments.csv`). Обычный `src/update.py` запускает сборку при изменении отслеживаемых источников; правка других локальных параметров сама по себе может не запустить пересчёт. `--force` обновляет внешние источники и пересчитывает цепочку.

Переключатель «Субсидия доступна» допускает отказ от выплаты, если специальный тариф снижает выручку сильнее суммы поддержки. При отборе сохраняется вариант сети без субсидии. В интерфейсе отдельно указаны выплата и изменение итога сети. Осторожный сценарий объединяет несколько неблагоприятных допущений; их сравнение раскрывается под переключателем.

Субсидия — сценарная оценка, а не подтверждённое право на выплату. Федеральная программа имеет условия по субъектам, аэропортам, расстоянию, прошлому потоку, периоду и отбору. Софинансирование, специальные исключения, договорные ставки и условия будущего года требуют отдельной проверки по [документам Росавиации](https://special.favt.gov.ru/dejatelnost-gosudarstvennaia-podderzhka-subsidii-drugoi-variant/?id=15106). Все текущие ограничения модели и найденные проблемы перечислены в `docs/33_case_readiness_audit.md`, если этот файл присутствует в рабочей копии.

Постановление Правительства РФ от 25.12.2013 № 1242 утратило силу в 2025 году. Ссылки на него как на действующее основание в ранее подготовленных материалах необходимо заменить после проверки применимых документов; подробности в `docs/35_population_transport_fares_subsidies.md`.

Модель спроса использует зоны тяготения аэропортов, данные связности и известные потоки. В [источнике связности](https://tochno.st/datasets/intercity_connectivity) время в пути рассчитано по средней скорости, а не по расписанию конкретного поезда. Если время поезда в исходной таблице отсутствует, для формулы подставляются 96 часов: это допущение, чувствительность к которому нужно проверять. Расписание и продажи конкурентов покрыты частично. Оценка поездок с пересадкой не является подтверждённым расписанием стыковок.

Все суммы отражают результат до аренды самолётов и расходов на базу. Спрос и будущие выплаты остаются модельными оценками. Денежные итоги округлены независимо от строк маршрутов.

Тарифная функция использует сценарные значения коллег по 31 паре. Это оценки чистой выручки, а не подтверждённые продажи билетов; её проверка на рыночных данных остаётся открытой.

Проверка источников и отдельные пересчёты по населению и расписаниям описаны в [docs/35_population_transport_fares_subsidies.md](docs/35_population_transport_fares_subsidies.md). Экспериментальные результаты не подключены к основной панели.

## Расчёт: лонглист городов (src/)

[Текущий интерфейс](https://redwings.altair.ad/). [Проверка 66 веток](docs/31_branch_review_20261111.md) и [актуальные расчётные таблицы](docs/32_current_model_results.md): перебор всех целых лимитов флота 2–10, одинаковый метод для итоговой сети и этапов роста. Полная сборка из сохранённых источников: `py -3.13 scripts/build_release.py`. Результат сети рассчитан до аренды самолётов и открытия базы.

Откуда какие данные — `docs/22_data_sources_longlist.md`. Нужен Python 3.13 с pandas и openpyxl.
```
py -3.13 src/fetch_static.py                      # OurAirports и «Если быть точным»
py -3.13 src/fetch_social.py                      # население 2025, населённые пункты, зарплаты (Росстат, «Точно»)
py -3.13 src/fetch_weather.py                     # погода в аэропортах, NOAA 2023–2024
py -3.13 src/fetch_kover.py --since 2024-11-01    # канал Росавиации об ограничениях, ~25 мин
# после смены версии парсера: тот же запуск с --rebuild (скачает всё заново)
py -3.13 src/longlist_data.py                     # население, дальность SSJ, прямые рейсы, поезда
py -3.13 src/kover_days.py                        # дни «Ковра» по аэропортам (названия берёт из зон тяготения)
py -3.13 src/catchment_extra.py                   # население 2025 всех пунктов, зарплата, погода
py -3.13 src/build_longlist.py                    # data/processed/longlist.csv и outputs/longlist.xlsx
py -3.13 src/build_dashboard.py                   # панель outputs/redwings_panel.html (табло, веса, карта, «Ковёр»)
```
Всё сразу одной командой: `py -3.13 src/update.py --force` — загрузка, проверки, лонглист, спрос по парам (docs/23), сравнение гипотез (docs/24), карты `outputs/map_hub.png` и `outputs/map_direct.png`, книга `outputs/redwings_model.xlsx`, панель.
Ручные данные со ссылками — `data/manual/longlist_manual.csv`.
